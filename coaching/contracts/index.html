코칭 맥락에 맞는
세 가지 계약

계약 생성 주체는 모두 담당 코치입니다. 고객은 코치가 발행한 초대 링크를 통해서만 확인하고 서명합니다.

01 / LIFE COACHING

라이프 코칭
계약 안내

개인 삶의 방향과 균형, 관계·역할, 습관과 실행을 다루는 성인 고객에게 적합합니다.

  • 주요 항목목표, 회기, 비용, 비밀보장, 기록·기술 사용
  • 당사자코치 + 실제 고객
  • 확인 시간약 10–15분
  • 생성 주체사전 협의한 담당 코치

심리치료·의료·법률·세무·투자 자문이 아니며 특정 변화를 보장하지 않습니다.

라이프 코칭 계약 안내

02 / BUSINESS COACHING

비즈니스 코칭
계약 안내

조직 스폰서 또는 비용 지급자가 있으며 보고 범위와 이해관계 조율이 필요한 경우에 적합합니다.

  • 주요 항목3자 역할, 보고 범위, 이해충돌, 종료 권한
  • 당사자코치 + 고객 + 스폰서/조직 담당자
  • 확인 시간약 15–20분
  • 생성 주체사전 협의한 담당 코치

기본 공유 범위는 출석·계약 진행 상태이며, 세션 원문·노트·개인적 발언은 공유하지 않습니다.

비즈니스 코칭 계약 안내

03 / CAREER COACHING

커리어 코칭
계약 안내

진로 탐색, 경력 전환, 취업 준비, 직무 선택과 검사 활용을 원하는 성인 고객에게 적합합니다.

  • 주요 항목목표, 정보 시점, 검사 활용, 지원·선택 책임
  • 당사자코치 + 실제 고객
  • 확인 시간약 10–15분
  • 생성 주체사전 협의한 담당 코치

취업·합격·연봉·승진을 보장하지 않으며, 채용 대행 또는 직업소개 계약이 아닙니다.
