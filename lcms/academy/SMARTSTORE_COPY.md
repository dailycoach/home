# 스마트스토어 등록 문구

## 상품명

**[온라인] LMC 평생진로상담사 2급 과정 | RS에듀컨설팅**

## 한 줄 소개

심리학 이론과 심리측정 실습을 연결하는 12주 상담코칭 전문과정

## 구매 후 안내 메시지

구매해 주셔서 감사합니다.

1. 아래 수강생 등록 신청서를 바로 작성해 주세요.  
   **신청서:** `setupAcademyAutomation()` 실행 후 생성된 URL
2. 신청서에는 스마트스토어 주문상세의 **상품주문번호**와 실제 강의에 사용할 **Google 계정 이메일**을 정확히 입력해 주세요.
3. 결제·주문 확인이 완료되면 입장코드가 이메일로 자동 발송됩니다.
4. 메일이 보이지 않으면 스팸함과 프로모션함을 확인해 주세요.
5. Google Drive 제한공유 영상은 신청서에 입력한 Google 계정으로 로그인해야 재생됩니다.
6. 입장코드와 강의 링크의 타인 공유는 허용되지 않습니다.

## 상세페이지 필수 안내

본 상품은 온라인 교육과정 수강권이며 실물 배송 상품이 아닙니다. 수강기간, 환불기준, 자격 발급요건, Drive 영상 접근조건을 결제 전에 확인해 주세요. 자격증은 과정 수강만으로 자동 발급되지 않으며, 수료시험과 별도 발급요건 충족 여부에 따라 발급됩니다.

## 운영 체크

- 디지털 콘텐츠 상품 유형과 배송설정 확인
- 수강기간 180일 표기

- 상품주문번호 확인 위치 안내 이미지 추가
- 신청서 URL을 구매 후 메시지와 상세페이지 양쪽에 삽입
- 테스트 구매 후 메시지 노출 여부 확인
