# 스마트스토어 등록 문구

## 상품명

**[온라인] LMC 평생진로상담사 2급 과정 | RS에듀컨설팅**

## 한 줄 소개

심리학 이론과 심리측정 실습을 연결하는 12주 상담코칭 전문과정

## 구매 후 안내 메시지

구매해 주셔서 감사합니다.

1. 아래 수강생 등록 신청서를 바로 작성해 주세요.
   **신청서:** `setupAcademyAutomation()` 실행 후 생성된 URL
2. 신청서에는 스마트스토어 주문상세의 **상품주문번호**와 입장코드를 받을 **이메일 주소**를 정확히 입력해 주세요.
3. 결제·주문 확인이 완료되면 8자리 입장코드가 이메일로 자동 발송됩니다.
4. 메일이 보이지 않으면 스팸함과 프로모션함을 확인해 주세요.
5. 별도의 영상 서비스 계정은 필요하지 않습니다. LMC 강의실 안에서 비공개 Cloudflare R2 방식으로 재생됩니다.
6. 입장코드와 강의실 주소의 타인 공유는 허용되지 않습니다.

## 상세페이지 필수 안내

본 상품은 온라인 교육과정 수강권이며 실물 배송 상품이 아닙니다. 수강기간, 환불기준, 자격 발급요건을 결제 전에 확인해 주세요. 1~11주는 구매자 전용 강의실에서 비공개 Cloudflare R2 영상으로 제공되며, 12주는 수료시험과 학기말 수료식으로 진행됩니다. 자격증은 과정 수강만으로 자동 발급되지 않으며, 수료시험과 별도 발급요건 충족 여부에 따라 발급됩니다.

## 운영 체크

- 디지털 콘텐츠 상품 유형과 배송설정 확인
- 수강기간 180일 표기
- 환불·청약철회 기준을 판매자센터 최신 정책과 대조
- 상품주문번호 확인 위치 안내 이미지 추가
- 신청서 URL을 구매 후 메시지와 상세페이지 양쪽에 삽입
- R2 버킷 Public access 비활성 확인
- 테스트 구매 후 메시지·입장코드 메일·R2 영상 재생 확인
