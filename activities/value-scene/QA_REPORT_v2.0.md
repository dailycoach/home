## 2. 전체 흐름 회귀 테스트

다음 실제 이벤트 흐름을 DOM 환경에서 끝까지 실행했다.

`COVER → COACH/일과 역할 → PICK 18 → CUT 10 → KEEP 5 → NOT THIS 5 → BUT THIS 2 → REAL SCENE → CLASH → THIS WEEK → RESULT → COPY/PRINT → 저장 후 재진입`

결과: 전 단계 통과, 콘솔 오류 0건.

## 3. 반응형·인쇄 검수

- 1040px, 760px, 380px 분기 규칙 적용
- 모바일 가치 카드 2열, 초소형 화면 1열 전환
- 주요 선택 버튼 최소 높이 42~52px 확보
- 결과 포스터 모바일 재배열 적용
- `prefers-reduced-motion` 대응
- A4 세로 인쇄 시 헤더·진행바·보조 카드 제외, 결과 포스터 중심 출력

## 4. 남은 운영 확인

클라우드 브라우저가 로컬 미리보기 주소를 차단해 실제 픽셀 스크린샷 검수는 완료하지 못했다. 구조·상호작용·반응형 규칙은 통과했으며, 운영 반영 전 배포 주소에서 다음 4가지만 최종 육안 확인한다.

1. 390px 모바일 첫 화면에서 `WHAT STAYS?` 줄바꿈
2. 외부 웹폰트 로딩 실패 시 폴백 타이포의 밀도
3. 결과 포스터 전체 화면 캡처 시 하단 잘림 여부
4. 브라우저 인쇄 미리보기에서 A4 1페이지 수렴 여부
