# 흐르는 강물처럼 Google Form · 운영관리 자동화

이 디렉터리는 신청용 Google Form, 연결 Spreadsheet, 운영관리 시트와 Instagram DM 복사용 문구를 생성하는 Apps Script 소스입니다. Instagram 로그인이나 자동 DM 발송은 하지 않습니다.

## 생성 결과

- 이메일·전화번호를 수집하지 않는 17문항 Google Form
- 원본 응답을 보존하는 `신청응답` 시트
- 상태 드롭다운과 정원 관리를 포함한 `운영관리` 시트
- 비공개 운영값을 저장하는 `설정` 시트
- 운영자가 직접 복사해 보내는 7종 Instagram DM 문구
- 제출 시 Instagram ID 정규화, 프로필 URL 생성, 결제 확인 인원 기준 대기 전환

## 설치

1. 생성된 `NAL_흐르는강물처럼_창립멤버_운영관리` Google Sheet를 열고 **확장 프로그램 → Apps Script**를 선택합니다.
2. 바인딩된 프로젝트에 `Code.gs`와 `appsscript.json`의 내용을 반영합니다.
3. 프로젝트 설정에서 표준 Google Cloud 프로젝트 또는 기본 프로젝트를 사용하고 V8 런타임을 유지합니다.
4. `setupFlowingRiverForm()`을 한 번 실행하고 Forms, Sheets, 트리거 권한을 승인합니다.
5. 실행 로그에서 Form 편집 URL·공개 URL과 Spreadsheet URL을 확인합니다.
6. Spreadsheet의 `설정` 시트에서 카카오톡 입장 링크, 참여코드, 입금계좌, 입금기한과 입장기한을 운영자가 직접 입력합니다. 초기 샘플 상태 행은 설치 함수가 자동으로 비웁니다.
7. 실제 제출 테스트 후 생성된 Form 공개 URL을 `nal/data/programs.json`의 `applicationUrl`과 `nal/data/launches.json`의 `actionUrl`에 같은 값으로 연결합니다.

## 운영 메뉴

Spreadsheet를 열면 `흐르는 강물처럼` 메뉴가 생성됩니다.

- 신청행 동기화
- DM 문구 다시 만들기
- 정원 확인
- 대기 상태 정리
- 운영 시트 재설정

## 공개 전 확인

- Form 설정에서 이메일 자동 수집과 응답 사본 발송이 꺼져 있는지 직접 확인
- 로그아웃 또는 시크릿 창에서 로그인 없이 제출 가능한지 확인
- 개인정보 동의 거부 시 제출이 막히는지 확인
- 모든 운영규칙·FLEX MOVE·참가비 체크박스를 전부 선택해야 진행되는지 확인
- 테스트 결제 상태를 `입금 확인`으로 바꾸었을 때 10명 이후 신규 신청이 `대기`로 분류되는지 확인
- Form 완료 화면이나 공개 사이트에 Zoom 링크, 카카오톡 링크, 참여코드가 없는지 확인

## 개인정보 보유기간

초안은 승인되지 않은 신청 정보를 처리 종료 후 30일 이내 삭제하고, 참여 확정 정보는 참여 종료 후 30일 이내 삭제하도록 안내합니다. 결제 관련 법정 보존 의무가 있는 기록은 해당 법령 기간을 따르도록 분리했습니다. 공개 전 운영자의 실제 보존정책과 법률 검토 결과에 맞게 `privacyDescription_()` 문구를 확정해야 합니다.

## 제한

이 소스는 Instagram 또는 카카오톡 인증정보를 저장하지 않으며 자동 로그인, 자동 DM, 비공식 크롤링과 브라우저 자동화를 수행하지 않습니다. Zoom 링크와 카카오톡 비공개 정보도 Form 완료 화면이나 공개 NAL 데이터에 기록하지 않습니다.
