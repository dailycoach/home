어디에서 멈추셨나요?

다시 이어갈 수 있는 곳을 함께 찾습니다. 이 안내는 로그인 없이 읽을 수 있습니다.

로그인 링크를 받지 못했어요.

구매하거나 참여할 때 사용한 이메일인지 먼저 확인해 주세요. 스팸함도 확인하고, 받은 링크는 로그인을 요청한 브라우저에서 열어보세요. 다른 계정을 만들거나 결제를 다시 할 필요는 없습니다.

이메일 수신이 해결되지 않았다면 개인 문의를 열지 못할 수 있습니다. 이 도움말은 계정 복구를 대신하거나 로그인 상태를 바꾸지 않습니다.

MY NAL 로그인 화면
결제했는데 프로그램이 보이지 않아요.

결제한 이메일과 현재 로그인한 이메일이 같은지 확인해 주세요. 내 주문에서 결제 결과와 참가권 연결 상태를 확인하고, 해결되지 않으면 해당 주문을 선택해 문의를 남겨주세요. 결과가 불명확한 상태에서는 다시 결제하지 마세요.

내 READ 주문 확인
오늘의 질문이 아직 열리지 않아요.

기수 시작일과 이전 DAY의 완료 상태를 확인해 주세요. 시작 전에는 준비 안내가 표시될 수 있습니다. 준비 체크를 모두 했다는 것과 질문의 공개·완료 상태는 서로 다릅니다.

참여 중인 READ 열기
쓰던 내용이 저장됐는지 모르겠어요.

화면에 표시된 저장 안내부터 확인해 주세요. 저장하지 못했다는 안내가 보이면 작성 중인 내용을 먼저 안전한 곳에 보관하고, 연결을 확인한 뒤 다시 저장해 주세요. 문의할 때는 개인 답변 대신 어느 화면에서 어떤 안내가 표시됐는지 적어도 됩니다.

화면·저장 문제 문의
LIVE 접속 주소를 어디에서 보나요?

참여 중인 시즌의 LIVE 화면에서 등록된 일정과 입장 가능 시간을 확인해 주세요. 상품 소개에 보이는 일정과 실제 접속 주소는 구분됩니다. 일정이나 기수 이름을 문의에 연결하면 상황을 설명하기 쉽습니다.

내 시즌으로 이동
취소·환불을 문의하고 싶어요.

내 주문의 참여·이용 안내와 현재 결제 상태를 먼저 확인해 주세요. 문의 접수, 답변 또는 문의의 해결됨 표시는 실제 취소·환불 완료를 뜻하지 않습니다. 결제 결과는 주문 상태에서 별도로 확인합니다.

주문과 취소·환불 문의 확인
문의에 남긴 내용은 누가 보나요?

직접 적은 글과 선택한 기수·주문 정보는 문의자와 소유자, 해당 문의에 배정된 운영자가 확인하는 구조입니다. 개인 코칭 답변, 화면 내용, 파일은 자동으로 가져오지 않습니다. 비밀번호·인증번호·카드번호는 남기지 마세요.

답변은 어디에서 확인하나요?

답변은 내 문의에 이어서 남습니다. 문자나 이메일을 자동 발송하는 서비스는 포함하지 않습니다. 내 문의 목록을 다시 열거나 새로 불러와 답변을 확인해 주세요. 개인 문의 기능은 현재 개발 중이며, 계정 연결 전에는 문의를 보내지 않습니다.
