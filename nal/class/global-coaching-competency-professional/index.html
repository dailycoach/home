글로벌 코칭역량

교육 시간은 개설 공고에서 안내 · 커리큘럼과 교육·개설 문의 안내

코칭 윤리와 마인드셋부터 관계 만들기, 효과적인 의사소통, 학습과 성장 지원까지 핵심역량을 코치의 실제 행동으로 연습합니다. PCC·MCC 수준에서 무엇을 다르게 보는지 질문과 코칭 장면을 중심으로 비교하고, 상황판단형 질문을 실제 코칭에 적용합니다.

교육 시간은 개설 공고에서 안내

교육 일정 · 신청 기간 · 수강료: 개별 문의

교육 커리큘럼

  1. 코칭의 기초 세우기 — 윤리적 실천과 코칭 마인드셋
  2. 관계 함께 만들기 — 합의 수립, 신뢰와 안전, 현존
  3. 효과적으로 소통하기 — 적극 경청과 알아차림 촉진
  4. 학습과 성장 북돋우기 — 성찰과 실행·성장 지원
  5. PCC·MCC 관찰 포인트 — 역량 차이를 실제 질문과 행동에서 비교
  6. SJT와 코칭 실습 — 상황판단 사례, 상호 코칭, 관찰 피드백

인정·수료 안내

ICF 핵심역량을 다루는 ACE 교육 모듈 기반의 공개 소개입니다. ICF·KCA 자격 인증, 교육시간 인정, 시험 응시 자격이 자동으로 부여되는 과정이라는 의미는 아닙니다. 세부 인정 범위는 개설 공고를 확인해 주세요.
