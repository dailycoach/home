1. 적용 범위

이 안내는 DAILYCOACHING이 운영하는 마음서재의 독서모임 참여 신청, 토스·웹 참여자 연결, 토스에서 전송한 기록의 확인, 공개 한줄톡과 도서뉴스 제공에 적용됩니다.

2. 처리하는 정보

  • 참여 신청 시 이름, 연락처, 이메일, 연령대, 독서 리듬, 온라인 참여 선호, 기대하는 점과 이용자가 선택해 작성한 문장
  • 신청 검토와 참여 안내를 위한 신청 상태, 접수 시각 및 운영 처리 기록
  • 참여자 연결 및 세션 유지에 필요한 식별값과 보안 정보
  • 이름 대신 화면에 표시할 별칭, 참여 기수 및 상태
  • 이용자가 토스 마음서재에서 작성해 전송한 책 제목, 문장, 성찰, 다음 한 걸음과 익명 공개 선택
  • 보안과 장애 대응을 위한 최소한의 접속·처리 기록

일회용 연결코드 원문, 기기 토큰, 세션 토큰은 화면이나 공개 한줄톡에 표시하지 않습니다. 서버에는 검증에 필요한 해시 등 보호된 형태를 사용합니다. 일반 참여자에게 ChatGPT·OpenAI 로그인을 요구하지 않습니다.

3. 이용 목적

참여 신청 확인과 일정 안내, 참여 자격 확인, 개인 기록 제공, 사용자가 선택한 익명 공개, 연결 해제, 서비스 보안, 운영 품질 개선을 위해 처리합니다.

4. 공개 범위

참여 신청서와 신청자의 연락 정보는 공개하지 않습니다. 새 독서 기록의 기본값은 비공개이며, 사용자가 익명 공개를 직접 선택한 기록만 공개 한줄톡에 나타납니다. 공개 화면에는 개인 이메일·전화번호·인증정보를 표시하지 않습니다.

5. 보관과 삭제

연결 해제 시 현재 참여 세션과 활성 연결을 종료합니다. 이미 익명 공개된 기록은 서비스의 대화 맥락과 운영 기록 보존을 위해 자동 삭제되지 않을 수 있습니다. 신청 정보 또는 기록 삭제가 필요한 경우 운영자에게 별도로 요청할 수 있습니다.

6. 안전 조치

일회용 연결 정보, 만료 시간이 있는 세션, 요청 출처 제한, 요청 빈도 제한, 변경 요청 보호와 운영 이력 기록을 적용합니다.
