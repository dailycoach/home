# 흐르는 강물처럼 Instagram DM 문구 v1.0

- 공식 계정: [@daily_coach_ing](https://www.instagram.com/daily_coach_ing/)
- 원칙: 운영자가 신청자와 내용을 확인한 뒤 직접 전송
- 금지: 자동 로그인, 자동 DM, 비밀번호 저장, 비공식 크롤링

대괄호 안의 값은 전송 전에 운영자가 실제 값으로 바꾼다. 카카오톡 링크, 참여코드와 계좌는 공개 페이지나 Google Form 완료 화면에 입력하지 않는다.

## 1. 신청자 신청완료 메시지

```text
흐르는 강물처럼 신청완료 / [신청자 이름]
```

## 2. 참가 승인·결제 안내

```text
안녕하세요, [이름]님.

흐르는 강물처럼 창립 멤버 신청이 확인되었습니다.

코칭을 사랑하는 사람들이 질문과 실천을 오래 이어가는 첫 커뮤니티에 함께 신청해 주셔서 감사합니다.

참가비는 월 10,000원이며 자동결제가 아닌 월 단위 수동 결제입니다.

입금 안내:
- 금액: 10,000원
- 입금계좌: [운영자 입력]
- 입금자명: [신청서 입금자명]
- 입금기한: [운영자 입력]

결제가 확인되면 이 Instagram DM으로 카카오톡 단톡방 입장 링크, 참여코드와 커뮤니티 안내문을 보내드립니다.

첫 Zoom은 2026년 9월 10일 오후 8:00~9:30에 진행합니다.
Zoom에서는 COACHING FLEX MOVE를 활용합니다.
https://daily-coach-ing.com/activities/coaching-flex-move/

입금 후 DM으로 "입금완료 / 이름"을 보내 주세요.
```

## 3. 결제 확인·입장 안내

```text
안녕하세요, [이름]님.

흐르는 강물처럼 창립 멤버 참가비가 확인되었습니다.

아래 링크를 통해 카카오톡 단톡방에 입장해 주세요.

- 카카오톡 입장 링크: [카카오톡 링크]
- 참여코드: [참여코드]
- 입장기한: [입장기한]
- 카카오톡 이름: [신청서 작성 이름]

입장 후 공지방의 운영규칙과 첫 Zoom 안내를 확인해 주세요.

첫 공식 Zoom:
- 날짜: 2026년 9월 10일
- 시간: 오후 8:00~9:30
- 주제: 코칭 이후, 나는 무엇을 보고 있었는가
- 활용 도구: COACHING FLEX MOVE

Zoom 링크는 단톡방에서 별도로 안내합니다.
```

## 4. 신청 대기 안내

```text
안녕하세요, [이름]님.

흐르는 강물처럼 신청이 확인되었습니다. 현재 신청 순서와 창립 멤버 정원을 확인하고 있습니다.

확정되는 대로 이 Instagram DM으로 안내드리겠습니다.
```

## 5. 정원 마감 안내

```text
안녕하세요, [이름]님.

흐르는 강물처럼 창립 멤버 10명 모집이 마감되어 대기 신청으로 접수되었습니다.

자리가 열리거나 다음 모집 일정이 확정되면 이 Instagram DM으로 먼저 안내드리겠습니다.
```

## 6. 미입금 안내

```text
안녕하세요, [이름]님.

흐르는 강물처럼 참가비 입금 여부를 확인하고 있습니다.

참여를 원하시면 안내드린 기한까지 입금 후 "입금완료 / 이름"을 보내 주세요. 일정 조정이 필요하면 이 DM으로 말씀해 주세요.
```

## 7. 첫 Zoom 리마인드

```text
안녕하세요, [이름]님.

흐르는 강물처럼 첫 Zoom은 2026년 9월 10일 오후 8:00~9:30입니다.

Zoom 링크는 카카오톡 단톡방 공지를 확인해 주세요. 고객을 식별할 정보 없이 COACHING FLEX MOVE에 사용할 최근 장면 하나를 준비해 주세요.
```

## 8. 다음 달 갱신 안내

```text
안녕하세요, [이름]님.

다음 달 흐르는 강물처럼 참여 여부를 확인합니다.

계속 참여하실 경우 월 참가비 10,000원을 안내된 계좌로 입금한 뒤 "갱신완료 / 이름"을 보내 주세요. 자동결제는 진행되지 않습니다.
```

## 9. 전송 전 체크

- [ ] Form의 이름과 Instagram ID가 일치하는지 확인
- [ ] 신청완료 DM 수신 여부 확인
- [ ] 승인·대기 상태 확인
- [ ] 입금자명과 입금 확인 여부 확인
- [ ] 계좌, 금액과 기한 확인
- [ ] 카카오톡 링크와 참여코드가 최신인지 확인
- [ ] 메시지에 이메일 안내가 없는지 확인
- [ ] Zoom 링크를 결제 확인 전 보내지 않았는지 확인
