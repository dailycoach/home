# NAL 사용자 테마

NAL 공통 메뉴의 **테마 → 기기 설정 / 밝게 / 어둡게**로 화면을 선택한다.
좁은 화면에서는 **메뉴 열기 → 테마**를 사용한다. 썸네일 이미지와 프로그램 정보는 유지한다.

- 기본값은 기기 설정이며, 운영체제 테마가 바뀌면 화면도 따라 바뀐다.
- 명시적으로 고른 밝게/어둡게는 기기 설정보다 우선한다.
- 선택은 이 브라우저의 `nal:theme:v1` localStorage에 저장된다. 회원가입이나 서버 저장이 필요하지 않다.
- NAL의 31개 페이지에서 같은 선택을 복원한다. 다른 기기와 외부 프로그램 사이트까지 동기화하지 않는다.
- 저장을 제한하는 브라우저에서도 현재 페이지의 테마 변경은 작동한다.

`nal/assets/js/theme.js`를 모든 NAL 문서의 CSS보다 먼저 실행하여 첫 화면에도 저장된 테마를 적용한다.
`nal/assets/css/nal.css`의 공통 의미별 색상 토큰과 `:root[data-theme="dark"]` 토큰을 함께 관리한다.
밝은 브랜드 배경 위의 글자와 이미지의 원래 색은 유지하고, 인쇄에는 밝은 색상을 사용한다.

공통 문서를 변경하면 `node scripts/generate-nal-pages.mjs`로 다시 생성한다.
검증은 `node scripts/check-nal-platform.mjs`와 `node scripts/check-nal-theme.mjs`로 실행한다.
실제 화면에서는 테마 선택 후 새로고침과 페이지 이동에서도 선택이 유지되는지 확인한다.
