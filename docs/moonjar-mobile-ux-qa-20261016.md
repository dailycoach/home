## 실제 브라우저 점검 (이번 단계에서 별도 수행 필요)
1. Android Chrome 360×780, 390×844 및 iOS Safari: 이야기와 함께 시작 → 01 장면의 짧은 에세이와 질문이 **캔버스 앞에 보이는지** 확인.
2. 다음 장면으로 이동 시 질문 카드가 해당 장면의 질문으로 바뀌고, 장면 기록으로 이동하거나 건너뛸 수 있는지 확인.
3. 바로 꾸미기에서는 불필요한 장면 소개 카드가 나타나지 않는지 확인.
4. 샴페인/민트/블루 등의 자개 3개 이상을 추가한 뒤 조절 탭 → 미니 작품이 유지되는 동안 이동·회전·크기 버튼으로 시각적 변화를 확인.
5. 미니 작품과 본 작품의 위치·비율·순서가 일치하는지 확인. 50개 이상의 조각과 스크롤·키보드 노출 때도 확인.
6. 잠시 바라보기 → 현재 장면의 질문이 캔버스 옆/위에 나타나고 편집은 차단되는지 확인. 내 말로 기록해 보기 → 입력 가능 모드로 돌아가는지 확인.
7. 07 돌아감의 처음 기록 항목이 '오늘 내가 알아차린 것은'인지 확인. 이후 상황·작은 행동·도움 순서 유지.
8. 이모지·한글 조합·붙여넣기로 입력 상한 초과를 시도하고 오류 메시지, 내용 보존, 저장 상태를 확인.
9. 저장 상태 확인 → 새로고침 → 조각·메모·기록 복원, PNG 작품만 출력, JSON 재가져오기, 인쇄를 검증.
10. 확대/축소·바탕 비교·두 탭 충돌·잠금/실행취소·공용기기 비저장 모드의 기존 동작이 유지되는지 확인.
11. Android 화면 키보드 표시/닫기 후 포커스, 고정 하단 탭, 미니 작품이 조작을 가리지 않는지 확인.
12. 화면 낭독기와 키보드 사용자에게 중복 미리보기가 과잉 낭독되지 않는지 확인.

## 판정 규칙
- 기능 자동 테스트 통과와 실제 모바일 UX 검증은 별개입니다.
- 저장/복원 불량, 입력 손실, 조작 불능, 개인 기록 노출은 **출시 차단(P0)**.
- 모바일 첫 장면 가독성, 미니 작품 가시성, 초점 이동, 한글 입력은 **필수 검증(P1)**.
- 이미지 권리·정확한 출처는 출시 전에 별도 확인합니다.
- 운영 주소를 변경하거나 메인 브랜치로 병합하기 전에 사용자 승인과 실제 기기 QA 결과가 필요합니다.
