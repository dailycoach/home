# 달항아리 아트디렉션 결정 — B형 폐기 · A형 단일 발전

**결정일:** 2026-10-19  
**결정 주체:** 상품 오너 명시적 지시 “B형은 폐기”  
**효력:** 즉시. 더 이상 B형을 옵션·완성 카드·테마·파일 선택지·설문 후보로 제안하지 않는다.

## 확정

**단일 미술 방향: A형 — 백자와 자개 중심 2.5D 공예형**.

- 빈 달항아리의 비대칭과 여백, 백자 유약의 깊이, 자개 원본의 조형미를 작품의 중심에 둔다.
- 사용자 자유로운 자개 배치·겹침·항아리 바깥 배치와 개인 작품의 주권을 계속 보존한다.
- 사용자 원본 자개 96종은 SHA-256 불변. 부착감/광학감은 비파괴 검토 전용 표현 층에서만 연구한다.
- 낮·밤은 **A형 안의 조명 선택**이다. B형과 별개의 현대미술 콜라주 테마는 사용하지 않는다.
- 최종 카드도 A형 백자 중심 아카이브 편집만 연구한다. 종이받침, 사전 지정된 원호, 배경 콜라주 프린트 등을 사용하지 않는다.

## 명확한 폐기 범위

1. **B형 한지 콜라주** 아트디렉션, 종이받침, 인쇄 원호, 스티커처럼 보이는 접착층, B 전용 카드 디자인.
2. A/B 비교를 위한 블라인드 평가 또는 취향 투표. 더 이상 이 구도를 상품 선호 설문으로 제시하지 않는다.
3. WAVE 9.5에서 제안했던 “작업실 A형 + 선택형 카드 B형” 혼합 전략.
4. 사용자 작품 JSON·PNG에 B형 변형 옵션 또는 필드를 신설하는 모든 로드맵.

기존 PR #199의 B 실험은 역사적 연구 흔적으로만 보관하고 **배포·재도입 계획을 철회**한다. 이 브랜치는 실험 PR #199가 아니라 **W9.4 공통 백자 자산 PR #198**을 바탕으로 시작했으므로 사용자 운영 코드나 오래된 B 시안을 활성화하지 않는다.

## 이번 구현 / 기술 검증

- `scripts/render-moonjar-craft.py`: A형에 필요한 원본 검사, 도자기 마스크, 제한적 곡면 표현, 미세한 반사, 자유 배치 및 단일 작품 카드만 독립 구성. B형 렌더러·종이 텍스처·콜라주 매트를 제외.
- `scripts/moonjar_craft_helpers.py`: 원본 자개 96개를 0·1·8·48·96개로 배치하는 QA용 좌표. **권장 미학 구성이나 심리적 의미 해석이 아님**.
- `design/moonjar-craft/review.html`: 낮·밤 및 배치 밀도 5종만 확인할 수 있는 **A형 단일 미술 감상 페이지**. A/B 비교 버튼·선택지는 존재하지 않음.
- `scripts/check-moonjar-craft.py`: 원본 96개 해시, 작품 10개(낮·밤 × 5밀도), 카드 2개, 전체 화면 1600×1800, 항아리 밖 배치가 잘리지 않는지 검증.
- `.github/workflows/moonjar-craft-only.yml`: 독립 연구 아트워크 자동 생성 및 검증. **운영 반영 없음**.

## 다음 단계: WAVE 9.6 재정의

이전 W9.6의 A/B 시각 선호도 실험을 **전면 취소**한다. 새 W9.6은 A형 하나의 예술적 품질 개선과 실물 사용자 작품 검토다.

1. 0개일 때 달항아리 자체의 조형·구연부·굽·유약 존재감.
2. 1·8개일 때 자개의 광학적 이질감과 자연스러운 배치/여백.
3. 48·96개일 때 조각 밀도·조형적 자유를 유지하며 발생하는 시각 혼잡 분석. 자동 “정답 배치” 금지.
4. A형 작품 카드의 제목·여백·인쇄 미감과 소장 욕구에 대한 개별 사용자 평가.
5. 실물 Android/iOS, 키보드/접근성, 실제 편집기 SVG/PNG/카드 정합성 검증 후에만 새 아트렌더링 방식의 앱 적용 검토.

**최종 상품성 검증은 참여자의 A형 작품 하나를 얼마나 간직하고 싶은가에 집중한다.**
