# Moonjar WAVE 9.9 · 전체 사용자 여정의 가독성과 저장 선택 개선

**2026-10-19 · A형 기존 ATELIER 디자인 보존 / B형 폐기 유지 / 연구 PR만 / 운영 main 무변경**

## 시작 기준

전체 사이트의 A형 백자 작업실 미감은 사용자 승인에 가깝다. 이전 Figma 독립 화면 시안을 다시 적용하지 않는다. 이번 작업은 기존 UX/UI의 색·글꼴·표면·백자 도안·자개 팔레트·실시간 드래그 영역을 손대지 않고, **작품 외 단계의 읽기·판단·보관**을 다듬는 두 번째 라운드다.

## 코드에서 확인된 개선 필요

1. **모바일 저장 모달**: 390×844 화면에서 원래 네 번째 저장 선택지가 화면 아래에 걸쳐 보이고, 대화상자 내부 스크롤을 알아차려야 했다.
2. **모바일 재료·개인정보 안내**: 원본 9개 긴 문단이 펼쳐진 채 이어져, 중요한 개인 기록 보관 경고와 단순 참고 사항의 위계가 흐려졌다.
3. **진행자 60분 안내**: 진행표·DAILY 질문·진행 윤리 사이에 한 번에 이동할 방법이 없어 모바일에서 상당히 긴 화면을 수동으로 탐색해야 했다.

## 이번 변경과 범위

### 저장·보관
- 한 줄 요약+실제 저장 범위 고지+4가지 선택의 정보 구조를 유지.
- 모바일 한정 카드 패딩·타이포·그리드를 줄이고, 각 버튼은 44px 이상의 터치 높이 유지.
- 390×844 환경에서는 마지막 4번까지 한 대화상자 화면에서 도달할 수 있도록; 320×568 초소형에서는 내부 스크롤을 통해 마지막 항목과 동작을 유지.
- PNG·카드·개인 JSON·인쇄 저장의 실제 이벤트나 데이터 계약은 전혀 변경하지 않음.

### 재료·개인정보
- 기존 **9개 문구를 한 글자도 삭제하지 않고** 접근 가능한 표준 `details/summary` 구조로 구성.
- 데스크톱은 9개 모두 처음부터 열어 기존 문서의 읽는 방식을 유지.
- 모바일은 기록 유실·공용 브라우저·개인 기록이 포함되는 편집 파일에 관한 핵심 4개 문구는 기본 열림; 일반 참고 5개만 접힘.
- 최상단에 편집 파일의 개인정보 범위를 단 한 번 명료하게 안내. 모든 접힌 항목은 키보드 Enter로 전개 가능.

### 60분 진행자 안내
- 맨 위에 **60분 순서 / DAILY 질문 / 진행 윤리** 세 개의 접근 가능한 이동 버튼 추가.
- 라우터의 `#/guide` 해시를 변경하지 않는 자체 포커스·스크롤 점프. 콘텐츠, 시간표, DAILY 5단계 질문 및 진행 윤리 문구 불변.
- 데스크톱은 기존 편집형 진행표를 유지하고, 모바일은 7개 진행 단계와 실제 질문을 유지.

## 최종 보호 범위

- 기존 영웅 이미지, 달항아리 배경 V2/구 V3, 자개 원본 96 PNG, 편집기 SVG/Canvas/PNG 렌더러와 작품 카드, 전체 IndexedDB/JSON 스키마 변경 0.
- 기존 휴대전화 한 화면 공방, 필드/도구/고정 레이아웃 변경 0.
- B형 콜라주 시안은 어떤 표현 방식에도 되살리지 않음.
- 새 Figma 제작 시안은 원본 작업실을 대체하지 않음.

## 검증

GitHub Actions W9.8의 실제 Chromium 1440×900 및 390×844, WebKit 390×844 세 화면에 **Chromium 320×568**를 추가한다.

화면의 외형뿐 아니라 실제 버튼 조작 및 키보드 Enter, 안내 길이 축소와 핵심 경고 기본 노출, 4번째 모바일 저장 선택지 가시성, 320px 대화상자 스크롤, 라우터 해시 보존, 전 사용자 여정의 수동 저장·복원/편집 호환성을 확인한다.
