# 달항아리 아트코칭 — WAVE 8 자개 96종 전수 시각 감사

**기준 운영본:** `main` @ `502bc53f2b595a010cc4ce64d23f22d456092e80`  
**평가일:** 2026-10-17  
**대상:** 자체 디자인 자개 8색상군 × 12개 = 96개, 백자 낮·달빛 밤 1600×1800 배경, 선택형 조각 윤곽 보기.  
**상태:** 원본 변경 없음 / 새 96종 시각 QA의 GitHub Actions 검증 대상.

## 문제와 평가 원칙

V2 유백색 백자에서 특히 밝은 자개의 가장자리가 배경에 묻히는 경우가 보인다. 진단은 **자개 디자인을 고치는 것이 아니라 사용자가 손쉽게 보고 선택하도록 돕는 것이 목적**이다. 자개는 자체 디자인이므로 별도의 제3자 이용권 미확인 경고를 반복하지 않는다.

기존 PNG 96개·썸네일 96개·백자 낮/밤·기존 선화 바탕·개인 작품/성찰 기록·JSON 데이터에는 어떠한 변경도 가하지 않는다.

### 실제 원본 전체 96개 로컬 색상 감사

원본 자개 `moonjar_artcoaching_png_v3.zip`의 **96개 PNG 원본**과 배포본 V2 **백자 낮/밤 PNG**를 비교한 결과이다. 각 조각의 색상·투명도를 보존한 채 백자 몸체의 대표 중앙 좌표에 합성한 후, 조각의 안쪽 약 3px 경계에서 **CIEDE2000 지각 색차(ΔE00)**를 계산했다. 아래 비율은 경계부 ΔE00 < 10인 픽셀의 비율이다. 작은 값일수록 주어진 중앙 샘플에서 상대적으로 구분하기 쉬운 경우가 많다.

이 수치는 **진단을 위한 휴리스틱일 뿐, WCAG 접근성 공식 인증/실제 사용자 시각 검사/결함 확정이 아니다.** 보는 자리·화면·색각·조명·확대에 따라 달라진다.

| 자개 색상군 | 낮의 경계부 낮은 색차 평균 | 해당 색상군의 우선 관찰 조각 |
|---|---:|---|
| A 샴페인 | 21.6% | A11·A02·A01 |
| B 민트 | 27.9% | B09·B02·B05 |
| C 블루 | 28.6% | C11·C12·C02 |
| D 로즈 | 23.9% | D06·D01·D12 |
| **E 펄** | **36.9%** | **E07·E11·E08** |
| F 딥블루 | 4.2% | F08·F01·F12 |
| G 코럴 | 13.5% | G05·G07·G06 |
| H 라일락 | 25.0% | H02·H09·H04 |

백자 낮 전체 96개 조각에서 해당 비율의 **중앙값은 약 23.3%**, 백자 밤의 유백색 몸체 중앙에서는 **약 17.9%**였다. 달빛 밤에서도 항아리 중심은 유백색이므로 일부 밝은 자개의 대비 부족이 완전히 해소되지는 않는다.

개별 조각 위험도 예시: **E07 (49.4%) · D06 (49.3%) · H02 (47.9%) · E11 (42.7%) · C11 (42.1%)**. 이 값만으로 조각별 사용을 금지하거나 색을 변형하지 않는다. 코칭 활동에서 어두운 자개를 선택하는 것이 정답이라는 메시지를 만들어서는 안 된다.

### 96종 실제 브라우저 검증 계약

`scripts/check-moonjar-nacre96.mjs`는 **실제 Materials 로더와 SVG 렌더러**를 사용해 96개 자개를 낮/밤 각각 표시한다.

- `light-96-original.png`, `light-96-guide.png`
- `dark-96-original.png`, `dark-96-guide.png`
- 테스트용 조각 ID(A01~H12)를 표시하는 컨택트시트이며, 실제 사용자 작품에 글자를 삽입하지 않는다.
- 원본/가이드 모두 **96개 조각 정상 로드** 및 선택형 윤곽 효과가 96개에 전부 적용되는지 검증한다.
- **가이드 ON/OFF를 바꿔도 사용자에게 저장되는 `exportPNG`의 SHA-256이 정확히 동일**해야 한다.
- 실패 시 CI를 실패로 판정한다. 배경 선택과 JSON 복원 등 기존 회귀 69개+Chromium 94개+WebKit/Chromium 매트릭스는 그대로 유지한다.

### 개선 우선순위

**P0 — 보존:** 원본 96종 색 보정 금지, 편집용 윤곽 효과가 PNG/카드/인쇄에 혼입되지 않을 것, 기록·스냅샷과 사용자가 선택한 배치 보존.

**P1 — 모바일:** E07/D06/H02/E11/C11 같은 저대비 조각을 모바일 320/390px에서 조절할 때 선택 상태/터치 정밀도, 확대했을 때의 과한 어두운 테두리 여부를 직접 확인해야 한다.

**P1 — 결과물:** 색상군별 PNG·작품 카드 전체 가시성은 선택형 가이드가 아니라 **원본 표현 그대로** 평가한다. 일부 자개가 백자와 자연스럽게 어우러지는 것은 디자인 특성이므로 무조건 선을 더하거나 자동 테두리를 합성하지 않는다.

**P1 — 복잡한 작품:** 자개 96종+160개 조각의 작업실 응답과 카드 PNG를 검증하고, 복원·개인 기록 접근에 오류가 없는지 확인한다.

**P2 — 지원:** 편집 중 명암 옵션 도움말이 접근성·실시간 화면을 방해하지 않도록 모달/포커스/터치 순서를 실제 Android TalkBack과 iOS VoiceOver에서 점검한다.

### 남아 있는 확인 사항

1. 실제 **Android Chrome / iPhone Safari 물리 기기 테스트는 수행하지 않았다.** 엔진 에뮬레이션 결과와 분리한다.
2. 인쇄·브라우저 카드의 실제 화질과 자개 인지 수준은 디자이너/참여자의 관찰이 필요하다. 점수 자동화만으로 최종 판정하지 않는다.
3. 기존 PDF 워크북은 웹앱의 이미지 배포와 별도 자산이다.

**정리:** 주요 위험은 E 펄 및 일부 D/H/C 저대비 조각의 **편집 단계 구분성**이다. 브랜드 감성과 사용자의 자율성을 지키기 위해 기존 WAVE7 '조각 윤곽 보기'를 **선택형으로 유지**하는 접근이 적절하다.
