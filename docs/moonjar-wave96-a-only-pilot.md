# MOONJAR WAVE 9.6 — A형 공예 단일 소장 경험·실사용자 파일 파일럿

**2026-10-19 / 연구 상태: 검토용 Draft / 실제 사용자 반응 수집 전 / 운영 사이트 무변경**

## 확정된 미술 방향

상품 오너의 지시로 B형 종이·한지 콜라주와 A/B 비교, B형 선택형 작품 카드, B형 설문은 모두 폐기. **A형 2.5D 백자·자개 공예 표현 하나만 유지**한다. 사용자 작품에 대한 자의적인 심리 해석, 자동 적정 배치, 자개 원본 변조는 하지 않는다.

## 이번 실구현

1. `design/moonjar-craft/pilot.html`: 수직 스크롤형 랜딩 페이지가 아닌 **한 화면 갤러리 + 카드 작업실 + 소장 가치 자발적 평가**. 낮·밤과 0/1/8/48/96 자개 배치를 A형 안에서 감상.
2. **내가 만든 작품 불러오기(선택):** 기존 달항아리 웹앱에서 수동 저장한 PNG(1600×1800, 최대 10MiB)를 **브라우저 메모리에서만** 읽고 A형 전용 아카이브 카드에 넣을 수 있다. 파일명·이미지 데이터는 평가 JSON에 들어가지 않는다. 로그인·업로드 서버·추적도 없으며 브라우저를 닫으면 입력 상태는 사라진다.
3. **소장용 카드:** 같은 A형 아카이브 디자인 하나만 제공하며 1600×2400 PNG를 사용자 요청으로 생성·저장. 제목과 한 문장은 사용자가 명시적으로 체크한 경우에만 그림에 들어간다. 초기 기본은 '문구 제외'이고 개인 코칭 기록을 자동 읽지 않는다.
4. **소장 가치 파일럿:** 작품성/소장 의향/출력 의향 각 1~7 척도, 60~90분 **진행자 포함** 아트코칭 가상 가격 선택, 선택형 의견. 이는 **실제 결제 행동과 다르며** 구매전환율이 아니다. 사용자 행동/표정·기존 코칭 기록·민감한 개인정보는 수집하지 않는다.
5. 자발적 저장을 누른 경우에만 **로컬 JSON 다운로드**. 외부 전송·자동 기록·계정 데이터베이스·서버 저장 없음.
6. `scripts/build-moonjar-craft-pilot.py`: A형 실제 PNG 10개를 **WebP lossless 픽셀 동일성**으로 검증해 로컬 `art-data.js`로 묶는다. 별도 CDN 없이 `file://`로 열어 PNG를 다운로드하는 독립 검토 패키지.
7. `scripts/check-moonjar-craft-pilot.mjs`: Chromium/WebKit 실제 렌더링, 카드 PNG 치수, 320/390/1440px 화면과 문서 스크롤, 업로드 후 한 화면 카드와 응답 JSON의 이미지 비포함, 네트워크 0, 저장 등 브라우저 검증.

## 검증과 한계

이 파일럿이 검증하는 것은 **A형 작품을 보았을 때 소장하고 싶은가**다. 기존 웹앱의 실제 자개 편집 성능을 대신 검증하는 것이 아니다. 사용자는 기존 도구에서 작품을 만든 후 수동으로 저장한 PNG를 업로드한다. 편집 데이터 자체는 도구의 로컬 저장/JSON에 그대로 남고 이 파일럿이 수정하지 않는다.

실제 사용자 응답은 현재 **0건**. 브라우저 자동 테스트에서 저장되거나 사용된 JSON은 전부 합성 테스트용이며 실사용자 평가로 계산하지 않는다. 이용자 인터뷰 10~15명 수준의 정성 조사와 기관 프로그램 유료 파일럿을 별도로 진행해야 한다.

### 실제 사용자 검증 진행안

- 각 참가자는 도구에서 자개를 자유롭게 배치해 작품을 하나 제작한다. 진행자는 심리 의미나 모범 배치를 유도하지 않는다.
- 완료 PNG를 이 브라우저의 A형 카드 작업실에 **직접 선택해** 불러온다.
- 카드 제목·문장 포함 여부는 본인이 결정하고 완성 결과물을 저장한다.
- 마지막 질문은 강요하지 않고, 참여자가 자발적으로 평가 JSON을 저장해 연구 진행자에게 제출할 수 있다.
- 디자인·완성품 소장 가치, 작품을 인쇄하고 싶은가, 실제 유료 신청·결제 행동의 차이를 구분한다. 참여자가 제출하지 않은 응답을 수집하거나 분석하지 않는다.
