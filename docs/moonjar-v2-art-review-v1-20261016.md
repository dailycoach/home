## 미술 평가(정성)
**개선:** 기존 균일한 윤곽선보다 좁은 입구, 풍성한 몸통, 보이는 유백색 바탕과 굽, 미세한 음영·광원으로 '백자'의 재질감이 분명해졌다. 야간에도 몸체가 검은 배경 속에서 사라지지 않는다. 빈 그릇도 하나의 작품처럼 보일 수 있어 여백을 남기는 활동에 적합하다.

**미완성/반영 전 검토:** 매우 밝은 진주빛 자개가 백자 고명도 영역에서 대비가 약해질 수 있다. 화면을 320px로 축소했을 때 자개 경계, 과도한 표면 입자감, 작업 프레임의 중복 그림자를 추가 평가해야 한다. 작고 다양한 자개가 놓인 결과 카드 전체의 타이포와 백자 배경 사이도 조정할 수 있다.

## 기존 프로젝트 보호(현재 구현 및 검증 범위)
- 기존 두 배경 PNG와 `outline-v3` scene 데이터를 덮어쓰지 않는다. 기존 자개 PNG 96개·썸네일 96개 바이너리도 변경하지 않는다.
- PR #190에서는 `scene.canvasVariant` 선택 필드를 추가하되, **없는 문서는 무조건 `legacy-outline-v3`**로 해석한다.
- `schema.json`의 strict 구조에 선택적 variant를 명시하고, `Editor.setCanvas()`, `renderSVG`, `Materials`, `drawScene`, PNG/카드를 공통 배경 해석기로 연결했다.
- 비교 모달에서 새/구 도안 낮·밤 4개를 보여주며, 기존 도안을 변경할 때는 확인 절차를 추가했다.
- 기존 JSON 가져오기와 스냅샷, 편집 기록 복원은 테스트한다. 실제 Android/iOS 기기 테스트는 별도다.
- **브라우저 스크린샷과 도안 자체에 대해 검토한 이후에만 운영 병합/배포**한다.
