**3차(상품성)**: 인쇄·카드·접근성·큰 화면 품질, PDF와 자산 대장 갱신.

## 하지 말 것
기존 `assets/canvas_light.png`와 `canvas_dark.png`를 강제 덮어쓰기 하지 않는다.  
원본 자개 PNG 96개 수정·색 보정·강제 테두리/그림자 저장을 하지 않는다.  
도안 밖 자개를 삭제하거나 마스크로 잘라내지 않는다.  
서사에 '달항아리는 완벽해야 한다'는 평가를 넣거나 조각 위치를 심리 진단하지 않는다.  
실제 iOS/Android 하드웨어 미검증을 PASS로 표시하지 않는다.
