# 빛을 담는 달항아리 · 2026-10-15

배포 경로: `/activities/moonjar/`. 로그인 없이 사용하는 독립 정적 웹앱이며 기존 홈페이지의 활동도구 메뉴 두 곳과 `pages.json`에 연결한다.

도착 → 그릇 → 자개 → 만남 → 전환 → 이름 → 돌아감의 원문 흐름과 모든 선택 기록을 유지한다. DAILY는 Detect / Acknowledge / Inquire / Link / Your Action을 따른다. 응답과 공유를 강제하지 않으며 작품을 심리적으로 판독하지 않는다.

## 데이터와 자산

원본 자개 PNG 96개와 도안 2개의 해시 및 크기를 검사한다. 첫 사진은 사용자가 제공한 출처 정보와 이미지 사용 승인을 반영했다. 특정 유물 번호나 공공누리 유형은 확인되지 않아 표시하지 않는다. 공개 실행 manifest에는 개인 승인 대화와 내부 검토 메타데이터를 포함하지 않는다.

작품과 기록은 이 앱 전용 IndexedDB 또는 메모리에만 남는다. PNG는 작품만, 편집 JSON은 성찰과 조각 메모까지 담는다. 가져오기는 새 작업으로 연다. DB·결제·AI API·분석 수집기를 추가하지 않았다.

## 검증

- `node scripts/check-moonjar.mjs`: JS 구문, 원본 98개 해시·치수, 미리보기 96개, 원격 전송 및 동적 HTML 삽입 탐지 검사 통과.
- `node --test tests/moonjar/*.test.js`: 45개 통과. 편집·되돌리기·문서 검증·저장 큐·IndexedDB 어댑터 이벤트 경계·실제 제어 함수의 바라보기 차단·홈페이지 로더 연결 검사 포함.
- 실제 PNG 생성: 제공 런타임의 Node Canvas 어댑터로 원본 96개를 사용해 밝은/어두운 1600×1800 이미지, 800×900 대안, 반복 결과와 공통 렌더러 픽셀 일치, 누락 재료 거부를 확인했다. 브라우저 캔버스·다운로드 검증과는 구분한다.
- 기존 APILOS 정적·검색·런타임 검사 통과.

브라우저 제어 도구가 제공되지 않아 실제 브라우저 조작, IndexedDB의 새로고침 복원, 모바일 터치·키보드·화면, 다운로드 및 인쇄 대화상자는 미검증이다. 제어 함수 및 어댑터 테스트를 해당 검증의 대체 통과로 보고하지 않는다. 원본 인수 테스트의 브라우저 검증 항목 역시 통과로 처리하지 않았다.
