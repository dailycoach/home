## UX 원칙

1. 작품을 가리는 장식·카드·효과를 추가하지 않는다.
2. 홈페이지와 작업실의 본문 스크롤 금지 구조를 유지한다. **안내·출처·보관 목록은 읽을 만큼 스크롤할 수 있도록** 한다.
3. 사용자 기록은 사진과 카드에 자동으로 실리지 않는다. PNG는 작품만, 편집 파일은 개인 기록을 포함하는 비암호화 백업으로 분명하게 구분한다.
4. '삭제'가 '이어서 꾸미기'와 같은 비중으로 보이지 않게 조정하지만, 삭제 접근성·확인 로직을 숨기지 않는다.
5. 320/390/768/1440px에서 글자 잘림·가로 스크롤·버튼 누락이 없어야 한다.
6. 모든 문구와 화면은 한국어 중심, 과도한 영문 브랜딩/새로운 컬러 테마/장식성 카드 남용 지양.
