## 이번 작업: 실제 이미지 생성과 비교

- `design/moonjar-wave93/porcelain-{day,night}.svg`: V3 기본 원본을 손질한 새 자체 제작 1600×1800 벡터 형상. 조선 백자의 풍만한 배·미세 비대칭, 손으로 빚은 구연부, 하단 굽을 재설계. 외부 저작물의 사진·이미지 임베딩 없음.
- `scripts/render-moonjar-wave93.py`: 곡면 법선 방향 확산광, 은은한 물레 성형 자국, 낮은 대비 유약 텍스처를 결합하는 결정론적 sRGB PNG 래스터 렌더러. 새로운 백자 이미지는 GitHub 소스에서 재생성 가능.
- 별도 검토 파일에서는 2개의 신규 PNG, SVG, WebP 미리보기, 0·1·8·48·96개 배치별 자개 96종 원본 합성, V2/V3/V3.1 낮밤 30개 장면, 미술 평가 보고서, 576개 개별 색채 지표와 모든 실제 원본 재료의 해시를 제공한다.
- 앱/DB/기존 사용자의 작품 저장 구조, 자개 원본 96개 및 현재 서비스 V2 도안은 전혀 변경하지 않는다.

## 현대미술·디자인 중간 평가

| 밀도 | 평가 |
|---|---|
| 0개 | 백자만으로 단정한 존재감이 있으나 실제 도공의 불완전한 성형·유약의 깊이를 충분히 복원한 것은 아니다. |
| 1개 | 구연부와 자개 재료 사이의 관계를 보는 기초 시안. |
| 8개 | 여백과 선택의 리듬은 잘 보임. 하지만 외곽 반사광과 자개 물성의 연결이 부족. |
| 48개 | 미적 자유를 유지하면서도 스티커/디지털 콜라주처럼 보이는 문제가 여전. |
| 96개 | 원본 자개 밀도와 항아리 밖 자유배치 가능성을 확인. 좋은 결과물에 대한 규범이나 자동 심리 해석은 제공하지 않음. |

**추가 위험:** 밤 V3.1의 옅은 청록색 캐스트가 백자의 정체성을 해치고 청자처럼 보일 수 있음. 원본 자개의 가시성 지표를 위해 작품의 재료 정체성을 희생해서는 안 된다. 예술 전문가·참가자의 육안 평가 필요.

## 기술·출시 게이트

1. 기존 배경 V2 낮밤 SHA-256과 자개 96종 SHA-256 불변.
2. `design/moonjar-wave93`의 SVG는 독립적인 미술 스터디이고 `activities/moonjar`의 `canvasVariant`나 렌더러에 참조되지 않는다.
3. 신규 PNG는 SVG 기하 + 렌더러 표면 보정으로 생성되어 **SVG 단독 렌더링과 픽셀이 같지 않다**. 정확한 재현을 원하면 `scripts/render-moonjar-wave93.py`를 사용하고 Python 라이브러리 버전을 고정해야 한다.
4. 사용자 원본 작품의 좌표·회전·크기·자유 배치·저장·내보내기·카드·개인 메모를 강제 변경하지 않는다.
5. 추후 서비스 연결 시에만 별도 `canvasVariant`, 신규 독립 경로/해시, 기존 작품 이전 방지, 실제 앱 SVG/PNG/카드 픽셀 일치, 320px 모바일 및 실기기 검증이 필요하다.
6. 상용 승인 전에는 **미술적 감수, 사용자 평가 및 실제 구매의향 검증**을 시행한다.
