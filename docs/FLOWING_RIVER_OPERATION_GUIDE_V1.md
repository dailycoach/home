# 흐르는 강물처럼 운영 가이드 v1.0

- 기준일: 2026-08-02
- 첫 공식 Zoom: 2026-09-10 20:00~21:30
- 공식 문의: Instagram [@daily_coach_ing](https://www.instagram.com/daily_coach_ing/)
- 프로그램: [NAL 흐르는 강물처럼](https://daily-coach-ing.com/nal/gather/flowing-river-coaches/)
- 상태: 런칭 준비 완료 · 실제 Google Form과 비공개 운영값 확정 전 배포 보류

## 1. 프로그램 정의

> 코칭을 잘하는 사람보다, 코칭을 사랑하는 사람들이 오래 연결되는 곳.

흐르는 강물처럼은 자격, 경력, 소속과 관계없이 코칭을 사랑하는 사람들이 연결되는 월간 커뮤니티다. 카카오톡 단톡방에서 질문과 실천을 나누고 주 1회 짧은 코칭 미션에 참여한다. 매월 10일 Zoom에서는 COACHING FLEX MOVE를 활용해 코칭 이후의 생각, 질문, 개입과 선택을 함께 돌아본다.

누군가를 평가하거나 정답을 가르치는 모임이 아니다. 코칭을 실제로 하고 있는 사람과 배우고 있는 사람이 서로의 장면을 안전하게 나누며 사고의 유연성을 확장한다.

## 3. 참여 흐름

1. 신청자가 NAL 상세 페이지에서 프로그램을 확인한다.
2. Google Form을 제출한다.
3. Instagram `@daily_coach_ing`을 팔로우하고 `흐르는 강물처럼 신청완료 / 신청자 이름`을 DM으로 보낸다.
4. 운영자가 Form 내용과 Instagram 계정을 확인한 뒤 승인·결제 안내를 DM으로 보낸다.
5. 신청자가 월 참가비 10,000원을 입금하고 `입금완료 / 이름`을 DM으로 보낸다.
6. 운영자가 입금을 확인한 뒤 같은 DM으로 카카오톡 링크, 참여코드, 안내문과 첫 Zoom 일정을 보낸다.
7. 신청자가 단톡방에 입장하고 주간 미션과 월간 Zoom에 참여한다.

이 흐름에서 이메일은 수집하거나 사용하지 않는다. Zoom 링크는 카카오톡 단톡방에서만 공지한다.

## 4. 운영자 처리 절차

### 신청 접수

1. `신청응답` 원본 시트는 수동 편집하지 않는다.
2. `운영관리`에서 새 신청자의 이름, Instagram ID와 코칭 연결 정보를 확인한다.
3. Instagram ID 프로필 링크를 열고 신청완료 DM 수신 여부를 확인한다.
4. `DM 확인`을 `신청완료 DM 확인`으로 바꾼다.
5. 입금 확인 인원이 10명 미만이면 `신청 상태`를 `승인`, 10명이면 `대기`로 정리한다.

### 승인과 결제

1. `DM문구` 시트에서 신청자를 선택한다.
2. `참가 승인·결제 안내` 문구의 계좌와 기한을 확인한다.
3. 운영자가 Instagram에서 직접 DM을 보낸다.
4. `결제 상태`를 `안내`로 바꾼다.
5. 입금이 확인되면 `입금 확인`으로 바꾼다. 정원은 신청 순서가 아니라 입금 확인 인원으로 집계한다.

### 입장 안내

1. 카카오톡 링크, 참여코드, 입장기한과 신청서의 카카오톡 이름을 대조한다.
2. `결제 확인·입장 안내` 문구를 운영자가 직접 DM으로 보낸다.
3. `입장 안내`를 `발송 완료`로 바꾼다.
4. 단톡방 입장이 확인되면 `단톡방 입장`을 `입장 완료`로 바꾼다.

### 월간 운영

1. 매주 월요일 해당 주차 미션을 단톡방에 게시한다.
2. 첫 Zoom 전 리마인드 DM 또는 단톡방 공지를 게시한다.
3. Zoom 링크는 단톡방에서만 공유하며 녹화하지 않는다.
4. Zoom 종료 후 `첫 Zoom` 참석 상태와 운영 메모를 기록한다.
5. 월말에 다음 달 참여 의사를 확인하고 수동 갱신 안내를 보낸다.

## 5. 정원과 대기 운영

- 정원은 `결제 상태 = 입금 확인`인 인원으로 계산한다.
- 10명째 입금 확인 시 운영자에게 정원 완료 경고를 표시한다.
- 정원 완료 후 새 신청은 자동으로 `대기` 상태가 된다.
- 기존 `검토 중` 신청을 일괄 대기로 바꾸려면 운영 메뉴의 `대기 상태 반영`을 사용한다.
- 취소나 미갱신으로 자리가 나면 대기 순서와 참여 적합성을 확인해 개별 DM으로 안내한다.

## 6. 운영관리 시트

### 신청응답

Google Form 원본 응답을 보존한다. 정렬, 삭제, 열 이동과 수동 상태 입력을 하지 않는다.

### 운영관리

신청일시, 이름, Instagram ID·URL, 카카오톡 이름, 입금자명, 코칭 연결, Zoom 가능 여부, 실제 코칭 경험, 신청·DM·결제·입장·단톡방·Zoom 상태와 운영 메모를 관리한다.

### 설정

공개값과 비공개값을 분리한다. 다음 값은 운영자만 입력한다.

- 카카오톡 입장 링크
- 카카오톡 참여코드
- 결제 계좌
- 입금기한
- 입장기한
- 최종 결제 안내문

이 값은 공개 NAL 데이터, Form 소개문, 제출 완료 화면, 저장소 문서에 입력하지 않는다.

### DM문구

승인·결제, 결제 확인·입장, 대기, 정원 마감, 미입금, 첫 Zoom, 다음 달 갱신의 7종 문구를 생성한다. 자동 전송 기능은 없으며 운영자가 신청자와 내용을 확인한 뒤 직접 복사해 보낸다.

## 7. 개인정보 수집·이용 안내 초안

- 수집 항목: 이름, Instagram 사용자 이름, 카카오톡 이름, 입금자명, 참여 신청 내용
- 이용 목적: 신청자 확인, 참가 승인, 결제 확인, 카카오톡 단톡방 입장 안내, Zoom 및 커뮤니티 운영
- 보유 기간: 신청 결과 통보일로부터 30일. 참가 승인·결제 완료자는 참여 종료 후 30일까지. 관계 법령상 보존 의무가 있는 결제 기록은 해당 기간 동안 분리 보관할 수 있다.
- 동의 거부: 동의를 거부할 권리가 있으나 신청자 확인과 운영 안내가 불가능하므로 참여 신청을 완료할 수 없다.

공개 전 운영자의 실제 보존정책과 법률 검토 결과에 맞게 보유 기간을 최종 확정한다.

## 8. 함께 지킬 약속

- 고객과 참여자를 식별할 수 있는 개인정보와 사례를 공유하지 않는다.
- 단톡방과 Zoom 내용을 캡처·녹음하거나 외부에 전달하지 않는다.
- 요청받지 않은 코칭, 해석과 조언을 제공하지 않는다.
- 운영자 동의 없이 홍보, 판매와 개인 영업을 하지 않는다.
- 자격, 경력과 소속을 근거로 다른 참여자를 평가하지 않는다.
- 차별, 혐오, 성희롱과 공격적인 표현을 사용하지 않는다.
- 반복적인 규칙 위반 시 참여가 제한될 수 있다.

- [ ] 개인정보 보유 기간 최종 확정
- [ ] 카카오톡방과 참여코드 입력
- [ ] 결제 계좌, 입금기한과 입장기한 입력
- [ ] 실제 Form URL을 NAL 신청 CTA에 연결
- [ ] Form·Sheet·DM·대기 처리 종단간 테스트
- [ ] 최종 승인 후 배포
