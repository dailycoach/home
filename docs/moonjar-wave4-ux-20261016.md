# WAVE 4 · 작품 중심 편집과 품질 높은 결과물

대상: DAILYCOACHING /activities/moonjar/ · PR #188 Draft (운영 미배포)  
구현일: 2026-10-16

## 문제 정의
기존 모바일은 자개를 조절할 때 캔버스 아래 별도 미니어처 SVG만 보고 작업해야 했습니다. 결과 카드의 문구는 원본 이미지 1600×2400을 축소하면 작게 읽히고, 텍스트가 길어지면 생략 기호(…)로 잘릴 위험이 있었습니다. 기존 성찰 기록이 50/100자보다 길면 카드 편집기에 자동으로 잘라 넣는 처리도 있었습니다.

## 이번 변경
- **모바일 실제 캔버스 중심 조절**: 본 달항아리 영역이 보이도록 스크롤하면서 화면 아래에 이동·회전·크기 버튼이 담긴 조절 패널을 띄웁니다. 기존 미니 SVG의 중복 렌더링을 제거했습니다. 패널을 닫거나 탭에서 다시 열 수 있습니다.
- **편집 대체 수단 유지**: 자개는 드래그 없이 버튼으로 움직일 수 있습니다. 크기 비례 유지, 48px 이상 터치 목표, 잠금과 레이어 순서·실행취소, 자유 배치를 유지합니다.
- **작품 카드 시각 개선**: 기존 1600×2400 규격과 전체 작품(항아리 밖 배치 포함)을 유지하고, 제목 기본 110px·한 문장 기본 76px으로 확대합니다. 길이에 따라 명시적인 최소값까지만 크기를 조정합니다.
- **문구 생략 금지**: 카드 영역에 글이 모두 들어가지 않으면 이미지 내보내기를 거부하고 사용자가 *카드용 문구*를 짧게 다듬도록 안내합니다. 숨은 말줄임표나 자동 글자 삭제는 하지 않습니다. 기존 코칭 기록 원문은 절대 수정하지 않습니다.
- **개인정보 보호 유지**: 카드 제목·한 문장 체크박스는 각각 기본 OFF입니다. 조각 메모와 성찰 전문은 자동으로 포함되지 않습니다.
- **출처**: WAVE 3에서 박물관 사진을 제거하고 자체 SVG를 사용합니다. 꾸미기용 자개 PNG·도안의 이용권한 확인은 출시 전 별도 진행해야 합니다.

## 후속 출시 차단
실제 Android Chrome 및 iPhone Safari의 터치/스크롤, 키보드·스크린리더와 작은 화면/큰 글자, 100조각 이상 사용 성능, 사진이 아닌 제공된 자개 이미지 및 도안의 권리 확인은 **자동 브라우저 QA에 포함되지 않습니다.** 해당 검증과 사용자 승인 전에는 Draft PR을 병합하거나 실제 웹페이지에 배포하지 않습니다.
