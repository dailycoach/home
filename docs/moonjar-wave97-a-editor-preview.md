# MOONJAR WAVE 9.7 · A형만 실제 편집기 데이터로 그려보는 미술 실증

**2026-10-19 · 개발 브랜치만 / Draft / 운영 배포 금지**

## 목적과 아트디렉션

오너 결정인 **B형 전면 폐기**를 유지하면서, A형 공예 시안이 기존 사용자의 실제 자개 배열·크기·회전·자유배치·자동저장에 영향을 주지 않고 편집기에서 출력 가능한지 직접 검증한다.

이번 통합은 **연구용 비파괴 미리보기 팝업**이다. 실시간 SVG 조작 화면 전체를 A형 엔진으로 교체하지 않으며, 새 배경을 사용자의 저장 문서에 기록하거나 기존 작품을 강제로 바꾸지 않는다.

## 실제 구현

- `?artStudy=craft-a`를 **명시적으로 입력**하면 현재 작업실과 결과 화면에만 「A형 공예 미술 시안」 버튼이 나타난다. 파라미터가 없으면 UI와 기존 이미지 출력은 동일하다.
- 버튼 클릭 시 **사용자가 실제 편집한 문서의 scene만** 읽어 복제하며, 개별 자개 assetId·x/y·width/height·rotation을 그대로 반영한다. 사용자의 성찰 기록, 조각 메모 및 프로젝트 ID는 연구용 이미지 생성기에 넘기지 않는다.
- A형 백자는 Python W9.4 자체 제작 낮/밤 백자 PNG를 **이미 검증된 SHA-256**으로 생성하여 **CI 격리 작업공간에만** 주입한다. 이미지·좌표를 저장 문서의 variant로 승격하지 않는다.
- 표현 효과는 소폭의 캔버스 그림자·확산 필터를 결합한 **A형 한정 시각적 근사**다. W9.5 Python 합성 픽셀, PBR·과학적 자개 광학 모델과 동일하다고 주장하지 않는다.
- **단일 Canvas 표현 함수를 공유**해서 A형 PNG 미리보기와 다운로드는 **동일한 blob bytes**를 사용한다. 카드에 들어가는 작품 영역 또한 해당 PNG를 직접 디코드해 그리므로 별개 렌더러가 작품을 다시 계산하지 않는다.
- A형 카드의 제목과 한 문장은 참가자가 각각 체크한 경우에만 이미지에 포함. 카드 문구가 허용 범위를 넘으면 **조용히 잘라내지 않고 오류**로 알려준다.
- 「기존 작품과 비교」는 A형 vs B형이 아니라 **같은 참여자의 기존 원본 출력 vs A형 임시 미술안** 비교다.

## 보존 규칙

1. 원본 자개 96개 PNG의 SHA와 모든 가로세로 픽셀 무변경.
2. 기존 작품 및 나만의 편집 파일(JSON, IndexedDB), 복구, 레이어 순서, 자유 배치, undo/redo, 낮/밤, 반영된 구 도안 무변경.
3. URL 파라미터는 문서에 저장되지 않는다. 연구 배경은 기존 `manifest.json`에 추가하지 않는다.
4. 프로젝트의 기존 SVG 렌더러, PNG 저장, 작품 카드 출력 함수 및 JSON 스키마 **변경 없음**.
5. A형 이미지는 사용자가 연구 버튼을 직접 클릭했을 때만 로컬에서 생성; 자동 외부 전송 없음.

## 자동 테스트 검증 항목

- URL 플래그 없는 일반 웹앱과 플래그 있는 A형 미술 팝업의 인터페이스 분리.
- 원본 자개를 실제 편집기에 추가한 후 해당 **실제 사용자 배치**를 A형으로 출력할 것.
- 미리보기 PNG와 저장 PNG SHA-256 **완전 일치**.
- 저장한 A형 작품과 A형 카드 내 작품 영역의 **동일한 Canvas 소스 사용/실제 픽셀 비교**.
- 기존 표현과 A형 표현은 서로 다른 이미지를 보이되 원본 저장 데이터는 동일하게 유지.
- 카드 제목/문장 기본 제외 및 오버플로 비절단.
- 1600×1800 A형 이미지, 1600×2400 A형 카드 및 기존 JSON 내 canvasVariant 무변경 검증.
- Chromium 데스크톱/모바일, WebKit 모바일 자동 검증. 실물 Android/iPhone과 VoiceOver/TalkBack은 아직 별도.

## 릴리스 판정

**A형 실제 편집기 미술 검토 실증용. 운영/상용 배포 금지.** 미술 감독의 구연부·굽·유약 승인 및 실사용자 시연 결과 전에는 W9.7 결과를 운영 기본 도안으로 승격하지 않는다. 이 단계는 WAVE9.5 Python 효과 전체가 라이브 실시간 SVG에 픽셀 일치로 통합되었다는 뜻이 아니다.

최종 아트 검토 및 QA artifact에는 로컬 서버로 실행 가능한 **전체 정적 편집기 복사본**, 미술 검토용 백자 PNG, QA 캡처/이미지/결과 JSON을 함께 담는다.
