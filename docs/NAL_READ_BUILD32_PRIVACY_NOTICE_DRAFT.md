# NAL READ · 개인정보 처리 및 권리 안내 — 검토용 원고

**상태: 법적 고지 미확정 / 공개 금지 / 판매 준비 전 작성본**

이 문서는 날빛이 실제 첫 기수에 사용할 수 있는 안내 초안입니다. 처리 주체, 연락처, 서비스별 보유기간, 위탁 및 국외이전 세부사항이 아직 확정되지 않았습니다. 현재 공개된 `/nal/policy/privacy/`를 대체하지 않았고, 실제 운영 안내로 사용해서는 안 됩니다.

## 누구의 기록인가요
읽다가 떠오른 장면과 질문에 남긴 글은 참가자가 작성한 기록입니다. NAL READ는 답변·진행 상태·실험 계획과 성찰·개인 LIVE 메모·리포트 보관본·준비 체크를 서버에 저장할 수 있는 구조입니다. 이 정보는 프로그램 운영·개인 기록 재열람 목적으로만 다뤄야 하며, 참가자가 동의 없이 다른 참가자에게 표시되지 않습니다.

운영자는 **정원, 등록 상태, 출석, 완료한 DAY 수**처럼 모임 운영에 필요한 정보만 볼 수 있어야 합니다. 진행자의 원고 화면에 개인 답변이 자동 노출되지 않습니다. 대화 녹음·녹화나 AI 도구에의 무단 입력은 허용되지 않습니다.

## 계정·주문·문의는 구분합니다
- 계정: 로그인 이메일과 현재 인증 상태. Supabase Auth의 별도 규칙과 관리 절차가 적용됩니다.
- 자기성찰 기록: 저장한 답변, 실험, 개인 LIVE 메모, 준비 체크, 리포트.
- 거래: 상품 주문, 결제 확인, 참가권 연결 및 환불 기록. 법률상 보존대상 거래 기록과 단순 코칭 기록을 분리해야 합니다.
- 문의: 고객이 직접 작성한 문의와 운영자 답변. 법정 분쟁기록과 일반 안내 문의의 보유 필요성이 달라질 수 있습니다.

## 기록 삭제나 탈퇴는 어떻게 요청하나요
NAL READ의 개인 기록 삭제 검토 요청과 계정 탈퇴·법정 보존 검토 요청은 구분해야 합니다. 요청을 접수했다고 데이터가 즉시 파기됐다고 표시하지 않습니다. 실제 요청 처리 전에는 **삭제될 기록과 별도 보존되어야 하는 거래·분쟁 기록**을 구분해 안내해야 합니다.

현재 구현한 접수 구조에서는 본인 확인을 거친 요청의 상태만 저장합니다. 복제된 실험 원문, 리포트 보관본, 법정 보존 기록, Auth 계정 및 저장소·백업 처리까지 완료하는 자동 삭제 실행기는 아직 마련되지 않았습니다. **고객용 실제 삭제 기능이 완성됐다는 의미가 아닙니다.**
