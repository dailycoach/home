- 기존 V2 낮/밤 배경 PNG도 manifest 해시 일치. 독립 V3 낮·밤은 미술 스터디 패키지의 SVG 기반 텍스처 PNG이고 현재 라이브 앱에는 등록되지 않았다.

- 정량 보조지표는 각각의 조각을 어깨·중앙·오른쪽 하부 세 지점에 놓았을 때, 반투명합성 후 도자기 원색과의 **CIEDE2000 ΔE00<10** 샘플 픽셀 비율이다. **이는 미술적 검토 우선순위용 대리 지표일 뿐 접근성 인증, 절대적 작품성 점수 또는 판매 성과가 아니다.**

## 시각·현대미술 종합 판단

1. **0조각:** V3는 기존 V2의 단색 얼룩이 줄어 여백과 존재감은 개선됐으나 구연부가 기계적이고 유약의 물질성이 충분하지 않다.
2. **8조각:** 구성과 빈 공간을 관찰하기 좋지만 조각이 실제 표면에 입혀진 듯한 광학적 통합이 부족하다.
3. **48·96조각:** 색채가 화려하지만 표면에 얹은 이미지가 밀집되어 **디지털 콜라주**에 가까워 보인다. 참여자가 항아리를 가득 채울 자유를 제한해서는 안 된다.
4. **편집/출력:** 원본 PNG의 색·투명도를 강제로 보정하거나 임의 윤곽선을 완성작에 넣지 않는다. 사용자의 미적 정답을 제안하지 않는다.
5. 단순 회색/어두운 음영 시안 실험에서도 밝은 자개의 근접색 비율이 오히려 커졌다. **무조건 백자를 어둡게 하는 것은 해결책이 아니다.** 해당 후보는 채택하지 않았다.
