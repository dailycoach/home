# NAL 우선 런칭 3종 v1

적용일: 2026-08-02

## 우선 런칭 라인업

1. 미술심리코칭 6주 과정
2. 흐르는 강물처럼 코치모임
3. 마음서재 독서모임

## 연결 방식

| 프로그램 | 상세 경로 | 현재 CTA | 정식 전환 방식 |
|---|---|---|---|
| 미술심리코칭 6주 과정 | `/programs/art-psychology-coaching/` | 이메일 참여 문의 | Google Form URL로 교체 |
| 흐르는 강물처럼 | `/nal/gather/flowing-river-coaches/` | Instagram DM 문의 | Google Form 신청 후 Instagram DM으로 승인·결제·입장 안내 |
| 마음서재 독서모임 | 외부 마음서재 사이트 | 온라인 서재·독서모임 입장 | 마음서재 내부 신청 흐름 유지 또는 Form 연결 |

## 구현 범위

- NAL 홈에 `NAL / NOW OPEN` 전용 섹션 추가
- 기존 홈 CTA를 `첫 런칭 3개 보기`와 `전체 모임·클래스 둘러보기`로 변경
- 별도 런칭 데이터 `/nal/data/launches.json` 추가
- 런칭 전용 CSS·JavaScript 분리
- 미술심리코칭 `config.js`의 빈 신청 링크를 이메일 문의로 개통
- 미술심리코칭 런타임에서 Google Form과 `mailto:`를 모두 지원
- JavaScript 비활성 환경에서도 우선 런칭 3종 링크 노출

## 운영 원칙

- 확정되지 않은 일정·장소·가격·정원은 생성하지 않는다.
- 현재 `오픈`은 프로그램의 실제 일정 확정이 아니라 참여 문의와 온라인 입장 경로 개통을 의미한다.
- 정식 모집 일정이 확정되면 NAL 프로그램 데이터의 상태·일정·신청 URL을 별도로 갱신한다.
- 이메일 문의는 임시 런칭 경로이며 Google Form 또는 카카오톡 입장 경로가 준비되면 교체한다.

## 정식 오픈 전 남은 입력

### 미술심리코칭
- 모집 시작일·종료일
- 6주 전체 일정
- 장소 또는 온라인 방식
- 정원·참가비
- Google Form
- 취소·환불 기준

### 흐르는 강물처럼
- 카카오톡 또는 커뮤니티 입장 방식
- 첫 Zoom 모임 일정
- 서울 오프라인 모임 운영 기준
- 참여 대상과 운영 규칙 최종본

### 마음서재
- 정기 Zoom 요일·시간
- 이번 달 선정 도서
- 참여 방식과 비용 여부
- 마음서재 내부 독서모임 CTA 확인

## 롤백

- NAL 홈에서 `launch.css`, `launch.js` 로드를 제거한다.
- `/nal/data/launches.json`과 관련 정적 파일을 제거한다.
- 미술심리코칭 `config.js`를 빈 URL로 되돌리고 기존 런타임으로 복구한다.
