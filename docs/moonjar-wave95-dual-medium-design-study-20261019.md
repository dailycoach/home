# WAVE 9.5 — 한 가지 달항아리, 두 가지 예술적 표현

**2026-10-19 · 실제 원본 자개 96종 사용 · 운영 사이트 미배포**

## 질문

**단순 PNG 장식이라는 인상을 극복하려면 실물 공예의 깊이를 시뮬레이션할 것인가, 아니면 디지털 콜라주라는 매체적 특성을 의도적으로 받아들일 것인가?** 이 스터디는 어느 쪽이 *판매된다*는 것을 검증하지 않는다. 사용자의 기존 작품과 96개 오리지널 자개 파일은 한 바이트도 수정하지 않았다.

## 결과물

- A **2.5D 공예형**: 기존 V3.2 백자의 형태를 유지하고, 절제된 곡면 변형·확산 반사·아주 약한 표면 접촉으로 나전이 놓인 듯한 인상을 연구했다. 밤 도안에서 청록색 착시를 줄이기 위해 **항아리 몸체만** 약간 중성화했다. **실제 PBR/물리 정확한 나전 시뮬레이션 아님**.
- B **현대미술 콜라주형**: 동일한 항아리 형상을 한지 재질의 커다란 종이 형상과 인쇄 원호, 정중앙의 여백으로 구성했다. 실제 자개마다 덱클(deckle) 질감의 종이받침을 작고 절제되게 배치했다. 이는 **의도적으로 스티커/콜라주를 매체로 택한 현대미술안**이지 전통 나전칠기를 흉내 낸 것이 아니다.
- 두 접근법에 **완전히 동일한** 0·1·8·48·96개 조각 ID, 좌표, 회전, 크기 상한을 적용했고, 낮/밤 각 5종 = **20개** 1600×1800px 원본 이미지를 생성.
- 두 접근법 × 낮/밤 × 8조각 = **4개** 1600×2400px 샘플 작품 카드. 카드 제목은 시안용 샘플로, 사적 기록·개인정보는 사용하지 않았다.
- 오프라인 웹 `index.html`은 비교 슬라이더·시간대·조각 밀도 5종을 동작시키며 각 작품 파일을 내려받을 수 있다. 외부 CDN/AI API 없음.
