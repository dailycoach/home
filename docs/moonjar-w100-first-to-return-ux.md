# MOONJAR WAVE 10.0 — 첫 방문부터 작품 보관과 다시 열기까지

**2026-10-19 / 기존 한 화면 공방 디자인 기준 / A형 공예 미감 유지 / B형 완전 폐기**

## 개선 목표

달항아리 백자·자개 제작을 반복하는 대신, 다음 서비스 디자인을 연결한다.

**첫 방문 → 자유롭게 꾸미기 → 잠시 바라보기(선택) → 작품 완성 → 안전하게 보관 → 나중에 다시 열기.**

이번 변경은 기능을 크게 늘리는 것보다 ‘내가 지금 어디에 있으며, 어떤 저장이 되는지’를 확실히 알려주는 마이크로 UX 개선이다.

## 발견한 우선 결함

사용자는 첫 화면에서 '이 기기에 저장'과 '기록을 남기지 않고 시작'을 선택할 수 있었다. 그러나 임시/공용기기 모드로 작품을 완성한 뒤 결과 화면은 저장된 작품과 거의 같은 모습이다. 저장 상태 글자는 있었지만 작품 카드 CTA에 비해 주목도가 낮았기 때문에, 이용자가 결과 화면을 **영구 보관 완료**로 오인할 위험이 있었다.

## 실제 적용

- **첫 화면:** 자개 고르기 → 자유로운 배치 → 작품 간직하기의 세 단계 문구를 기존 시작 버튼 아래의 조용한 보조 텍스트에 배치. 기존 최초 CTA, 원본 달항아리 일러스트, 로그인 없이/기록 선택 고지를 제거하지 않음.
- **임시 모드에서 완성:** '화면에만 남아 있음/닫으면 복원 불가/편집 파일로 내려받기/개인 기록 포함'의 네 가지 중요한 사실을 작품 아래의 조용한 황동색 인디케이터로 안내.
- **저장·복원 모드에서 완성:** 기존 저장 상태와 버튼 그대로. 임시 작업 경고를 표시하지 않아 저장 방식을 왜곡하지 않음.
- **내 작업 아카이브:** 완성한 항아리는 '완성 작품 보기'로 열어 감상 화면에 머무르고, 다시 꾸밀 때만 '다시 꾸미기'를 선택. 아직 만들고 있는 작품은 '이어서 꾸미기'로 바로 편집 화면에 이동. 저장 데이터와 배경 변형은 변경하지 않음.
- **파일 내보내기:** 임시 모드에서는 실제 복원이 가능한 기존 `export-json` 버튼을 완료 행동의 첫 번째에 배치해 중요한 안내가 화면 아래에 숨지 않도록 한다. 저장 모드에서는 원래처럼 작품 카드 버튼이 첫 번째다. 두 모드 모두 기존 다섯 가지 행동만 유지하며, 사용자 클릭 후 원본 JSON 다운로드. 복제 버튼이나 자동 저장·전송을 추가하지 않음.
- **보존:** 96 자개 원본과 백자, A형 공방 레이아웃, 원본 SVG/PNG/카드 생성, IndexedDB DB/JSON 스키마, 코칭 기록 및 기존 사용자 보관함 변경하지 않음.

## QA 중 발견해 수정한 실제 복원 오류

테스트 과정에서 같은 브라우저 탭의 `#/projects` 화면으로 이동한 뒤 이미 완성된 작품을 다시 열면, 변경된 해시 라우트가 페이지를 실제로 새로고침하지 않아 이전 편집기의 **Web Lock이 잠시 남는 문제**를 확인했다. 기존 `dispose()`는 해제 신호만 전하고 Web Lock API의 Promise 완료를 기다리지 않아, 새 편집기가 자기 자신을 **'다른 탭에서 편집 중'**으로 오해해 읽기 전용으로 열릴 수 있었다.

이 문제는 자개 아트가 아니라 **저장·보관·복원 여정의 실제 UX 및 데이터 안전 문제**다. `dispose()`에서 잠금 해제 콜백 뒤 lock request Promise의 실제 종료를 기다린 다음 재취득하도록 수정했다. 원래 DB 리비전 충돌 보호와 별개의 탭 간 배타 잠금 정책은 그대로 유지한다.

회귀 QA는 이제 완성 작품 열기 → 감상 → 다시 꾸미기 → 자동 저장 → 아카이브에서 이어하기까지 검사한다.

## 검증

`scripts/check-moonjar-w100-flow.mjs`:

- 브라우저 4개 조건: Chromium **320×568**, **390×844**, **1440×900**, WebKit **390×844**.
- 별도 브라우저 프로필에서 **임시 모드**로 새 작품 제작 → 완성 → 경고 표시 확인 → 파일 직접 저장 → 페이지 다시 열고 개인 아카이브에 해당 작업이 없음을 확인.
- **저장 모드**로 별도 작품 제작 → 완성 → 필요 없는 임시 경고가 없는지 확인 → 보관 목록에서 작품 재개, 자개 조각 유지 확인.
- URL/외부 네트워크 요청 0, 누락된 이미지/JS 오류 0, 기존 5개의 완성 CTA 보존.
- 390×844 이상에서 첫 시작 버튼을 원본처럼 첫 화면에 노출하고, 320px 초소형은 필요한 경우 홈 내부 스크롤 허용.

실물 모바일 기기, 사용자의 기억 정도, 디지털리터러시·코칭 효과는 자동 테스트가 검증하지 못한다.
