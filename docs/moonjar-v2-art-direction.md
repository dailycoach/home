# DAILYCOACHING 오리지널 달항아리 — PORCELAIN V2 미술감독 결정

2026-10-16 · Draft PR #190 · 자체 제작 자산 / 국립중앙박물관 사진 미사용

## 직접 제작한 결과물
`scripts/build-moonjar-v2.py`에서 재현 가능한 Python/SVG 기반으로 생성한다.
- 원본 벡터: `activities/moonjar/assets/moonjar-v2/master/porcelain-{day,night}.svg` — 1600×1800
- 편집용 래스터: `porcelain-day.png`, `porcelain-night.png` — 정확히 1600×1800
- 팔레트 미리보기: `thumbnail-{day,night}.webp` — 400×450
- 바이트·SHA256·크기: `assets/moonjar-v2/variants.json`.
- 기존 자체 제작 자개 8색군 96조각과 기존 도안 V3 PNG는 변형하거나 다시 압축하지 않는다.

## 조형 결정
긴장감 있는 비대칭: 몸체 왼쪽 최대 폭 x218, 오른쪽 x~1382. 입구 지름 약 314px로 최대 폭의 약 0.27, 굽은 약 220px. 어깨가 천천히 벌어지고 배가 넉넉해지는 구조, 미세한 흔들림을 허용한다. 기존의 과하게 넓은 입구 타원과 평면 윤곽선 문제를 해결한다.

## 재료감 및 광학
도자기 몸체는 유백색(중앙 밝기), 우하단의 완만한 세이지 음영, 낮은 대비로 그려진 얇은 유약 흔적과 미세 입자 약 300점/선 29개, 낮은 접지 그림자. 단일 광원의 강한 노란색 하이라이트와 검은 외곽 테두리를 배제했다. 진주층·자개 원본 그림에 새 그림자/색을 강제로 덧칠하지 않는다.

**Daylight**: 바탕 #F7F4ED→#EEECE5, 본체는 아이보리/상아색에 부드러운 광원. 밝은 자개 A·D·E·H가 완전히 사라지지 않도록 본체 그림자/경계를 낮은 강도로 제공.

**Moonlit**: 배경 #10262D→#193840, 본체는 여전히 유백색, 외곽과 음영만 차갑게. '어두운 바탕의 밝은 선화'로 돌아가지 않는 것이 필수다.

## 코칭 디자인 원칙
달항아리 위에 이미 자개 패턴을 프린트하지 않는다. 작품의 선택과 빈 공간은 참가자의 것이며 바탕을 고른 이유를 심리 검사처럼 해석하지 않는다. 작품 종이 전체 1600×1800을 출력하여 항아리 밖에 놓은 자개도 유지한다.

## 시각 검증
빈 작품, A~H 실제 자개 8개 배치, 4가지 원본/새 배경 비교, 모바일 축소, SVG/PNG/카드 동일성. 오리지널 SVG는 편집 가능한 구조로 유지하며 PNG와 WebP는 자동 생성 자산이다. 기존 V3 배경의 완성 이미지를 사용자의 명시적 선택 없이 V2로 교체하지 않는다.

> **현재 상태**: V2 디자인 자산 생성과 호환 가능한 웹 편집기 구현, 자동 테스트 진행 중. 실물 Android/iOS 디바이스와 실제 전문가의 최종 미술 검토는 아직 별도 단계.
