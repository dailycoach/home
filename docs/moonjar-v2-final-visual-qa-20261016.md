# 달항아리 PORCELAIN V2 — 실제 화면 최종 평가 및 배포 게이트

**평가일** 2026-10-16  
**대상** PR #190 — 사용자 승인 후 배포 후보  
**실제 증거** GitHub Actions `Moonjar UX Regression`의 390×844 모바일/1440×900 데스크톱 브라우저 캡처, `assets/moonjar-v2/` 원본 SVG·PNG, 기존 1600×1800 도안 2종, A~H 자개 96종.

## 종합 판정

**기술 구현: 출시 후보 수준 / 디자인: 조건부 합격 / 실제 Android·iOS 실기기: 미검증.**

V2 낮과 밤 모두 원본 종이 선화보다 입체감·형태·재료감이 크게 좋아졌다. 특히 달빛 밤에서 백자의 존재감이 유지된다. 자개를 8종 올린 뒤에도 큰 이미지에서 외곽 형태가 식별된다.

다만 자개 도안 일부는 백자와 명도 대비가 낮고, 도자기 몸체의 미세 무늬가 비늘/수채화처럼 보일 가능성이 있어 다음 디자인 패치에서 **마감 수준**을 조절할 필요가 있다. 기존 자개의 원본 색상·크기·형태는 변경하지 않는다.

## 실제 화면에서 발견한 품질 문제와 수정

| 구분 | 확인된 현상 | 판정 | 수정/남은 사항 |
|---|---|---|---|
| 백자 낮 | 따뜻한 미백색 몸체가 자개보다 과하게 튀지 않으며 실루엣은 포근하다 | 합격 | 피부 같은 마블 무늬/반점 느낌은 후속 저감 대상 |
| 달빛 밤 | 청먹색 바탕 위에서 항아리가 선이 아닌 실제 표면으로 보인다 | 합격 | 자개 C/F/H 광채가 강한 구역에서 시각 충돌하는지 추가 UX 체크 |
| 모바일 작업실 | 390×844에서 실제 항아리와 선택 조각이 하단 조절 패널 위에 보인다 | 자동 검증 | 320px·키보드·실기기 사용성은 별도 |
| 자개 8개 결과 | 비교적 자연스러운 구성, 흰 계열의 경계가 희미할 수 있다 | 조건부 합격 | 강제 테두리 저장 금지. 선택 테두리는 편집 UI에서만 사용 |
| 작품 카드 | 1600×2400 PNG로 작품과 개인 선택 문구가 출력된다 | 합격 | 밝은 백자 주변 여백의 감성 품질은 추가 모니터 |
| **작품 카드 모바일 저장** | 카드 미리보기 아래 저장 버튼이 초기 viewport 밖에 있어 찾기 불편 | **발견·수정** | 카드 모달에서 저장 영역을 모바일용 sticky footer로 설계. 실제 브라우저 검증 필수 |
| 기존 작품 호환 | 구형 V3 JSON이 V2 강제 전환 없이 원래 바탕으로 열린다 | 자동 검증 합격 | 실제 사용자가 저장한 백업 데이터로 재현하면 더 좋음 |
| V3→V2 변경 | 사용자가 선택한 경우에만 별도 확인 후 전환, 되돌리기 지원 | 자동 검증 합격 | 사용자 기록, 자개 좌표, 스냅샷을 유지 |
| 개인정보 | 카드 제목·한 문장 기본 OFF, 기록과 조각 메모의 자동 포함 없음 | 자동 검증 합격 | 공용기기 안내 및 실기기 공유 화면 별도 확인 |
| 성찰 흐름 | 달항아리 작업과 7단계 알아차림 질문 연결 | 적정 | 의미의 심리적 판독·정답 작품 제안 금지 |
| 화면 접근성 | 저장 알림·키보드 대체 조작·복원 알림 구현 | 코드 확인 | TalkBack/VoiceOver와 큰 글씨는 실기기 별도 |

## 무엇이 바뀌지 않았는가

1. 자개 원본 96개 및 썸네일 96개와 기존 도안 light/dark 바이너리 모두 보존.
2. 기존 `schemaVersion:1.0.0`, `templateId:outline-v3` 문서를 강제 변환하지 않음. 신규 `canvasVariant`는 optional.
3. 기존 사용자가 저장한 위치·회전·크기·메모·성찰·스냅샷의 의미를 바꾸지 않음.
4. 사용자가 자개를 그릇 밖에 놓을 자유를 제한하지 않음.
5. 개인의 기억과 작품 이미지를 외부 API로 자동 전송하지 않음.

## 배포 전 최종 검사

- Node 단위 테스트 전체 PASS
- Chromium 390×844 브라우저 흐름 (신규 V2 선택·편집·저장·PNG·카드·기존 V3 가져오기) PASS
- WebKit+Chromium 320/360/390/430px 11 시나리오 검사 PASS
- 자개 160개 부하 테스트 PASS
- 작품 카드 모바일 sticky 저장 버튼의 실제 위치 및 이미지 출력 확인
- `main` 최신 변경과 PR의 병합 충돌 없는지 확인
- GitHub Pages 배포 성공 및 새 도안 HTTP 200, 기존 도안 HTTP 200 확인
- `assets/moonjar-v2/variants.json` SHA256·1600×1800 이미지·SVG 원본 확인

**실제 모바일 물리 기기의 키보드·터치, Safari 다운로드, 접근성 사용성은 위 자동 검사로 PASS를 대체하지 않는다.**

## 사용자 관점의 배포 설명

새 작업: 오리지널 백자 낮에서 시작하며 달빛 밤과 기존 선화로 바탕 변경 가능.  
기존 작업: 이전에 꾸민 그림과 배경이 그대로 보이며, 새 백자로 전환은 **명시적 선택 + 확인**으로만 작동.  
모바일: 작업실에서 자개를 고르고 실제 작품을 보면서 조절. 작품 완료 후 개인 선택 문구가 포함된 카드 저장 가능.

## 배포 결과 기입 규칙

최종 프로덕션 배포 링크·커밋·배포 workflow PASS 및 수동 실기기 검증 여부를 별도 기록한다. **PR 자동 테스트 PASS와 고객 운영 LIVE를 혼동하지 않는다.**
