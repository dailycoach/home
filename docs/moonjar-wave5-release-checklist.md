## 자동 검증 범위와 해석

`scripts/check-moonjar-release.mjs`와 GitHub Actions의 `release-matrix`는 Playwright **Chromium 모바일 에뮬레이션**과 **WebKit 브라우저 엔진**으로 검증한다. 이는 실제 Android Chrome 앱, iOS Safari 기기, 디바이스의 접근성 API·가상 키보드 동작을 완전히 대체하지 않는다.

개발 브랜치에서 자동화로 통과한 항목과, 실제 기기에서 확인한 항목은 별개로 보고해야 한다. **실기기 미검증을 PASS라고 표기하지 않는다.**

실기기 검증은 개인정보가 들어있지 않은 테스트 작품으로 실시한다. 공용기기 저장소는 테스트 후 정리한다.

## 권리증빙 기준

`docs/moonjar-rights-register-20261016.md` 참고. 오리지널 첫 화면 달항아리 SVG는 별도 제작했다. 그러나 사용자 제공 이미지와 그것에서 생성된 자개 96개, 달항아리 도안 2종의 원본 저작물 이용권한은 자동검사로 증명할 수 없다. 권리자/라이선스 문서/상업적 웹 공개·다운로드·2차 제작 범위를 확인하여야 한다.

## 운영 승인 절차

G0~G10 중 **P0 오류·권리 확인 미완료**가 하나라도 있으면 공개 배포를 보류한다. 관련 증빙 없이 명시적인 출시 완료 보고를 하지 않는다.

수정·검증은 별도 GitHub 브랜치에서 진행하고 **사용자 요청 없이 운영 브랜치에 병합하지 않는다**. 운영 반영 시에는 새 정적 자산 경로와 기존 사용자 IndexedDB 저장본 호환성, 캐시, 도구 메뉴 링크 2개, 작품 PNG/카드/편집 JSON 파일을 다시 확인한다.

### 추가 테스트로 발견하여 바로잡은 실제 결함

1. `내 작업` 화면에서 클릭 이벤트와 URL 해시 변경 이벤트가 겹쳐 **저장된 작품 카드가 두 번 나타날 수 있는 비동기 중복 렌더링 문제**를 수정했다. 오래된 요청의 결과를 무시하는 epoch 보호를 추가했다.
2. 모바일 조절 패널 위에 5초짜리 검은 토스트가 겹쳐 **조절 내용을 가리는 시각적 문제**를 수정했다. 패널이 열린 동안은 패널 안에서 조각 추가 안내를 전달한다.
3. 저장 상태를 `role=status`와 `aria-live=polite`로 알리고, 조절 패널을 닫으면 작품 영역으로 키보드 초점을 돌려준다.

### 남아 있는 출시 차단 항목

자동검증 결과만으로 완성/운영 PASS를 선언하지 않는다. **실제 Android Chrome과 iPhone Safari, 기기 접근성 및 가상 키보드 테스트 미완료**, 자개 이미지 8개 원본 및 도안 2개의 **공개·상업적 이용권한 증빙 미확인**, 사용자 최종 화면 승인, PR 병합 및 배포 후 HTTP·캐시·데이터 복구 점검이 남았다.
