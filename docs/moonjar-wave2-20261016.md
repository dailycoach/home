# 달항아리 알아차림 아트코칭 WAVE 2 — 편집 몰입과 작품 카드
2026-10-16 · 리뷰 후보 · 운영 미배포

## 제품 원칙
- 작품을 고쳐서 '더 좋은 사람'으로 만드는 도구가 아니라 선택하는 자신을 알아차리는 활동이다.
- 사용자의 조각 위치나 색에서 성격·심리를 추정하지 않는다.
- 의미를 말하지 않아도 작품을 만들고 마칠 수 있다.
- 성찰 기록과 조각 메모는 별도 승인 없이는 내보낸 공유 이미지에 들어가지 않는다.

## 카드 작동 기준
1. 카드 편집 모달을 처음 열면 **체크박스 두 개가 모두 해제**되어 있다.
2. 체크하지 않은 문구는 제목/문장이 입력창에 있어도 이미지에 **절대 포함되지 않는다**.
3. 사용자가 체크한 텍스트는 카드 미리보기(640×960)와 다운로드(1600×2400)에 동일한 렌더러로 반영된다.
4. 카드 문구 최대 길이는 제목 50자 / 한 문장 100자이며, 초과할 경우 내보내기를 거부한다.
5. 저장 동작은 **사용자가 카드 미리보기를 확인한 뒤** 선택한다. 모바일 DOM 읽기 순서도 문구 선택 → 미리보기 → 저장이다.
6. 카드는 개인 정보가 자동으로 포함되지 않더라도 작품 자체의 의미가 개인적일 수 있음을 안내한다.
7. 카드 생성은 정적 자산·브라우저 캔버스에서만 이루어지며 별도의 서버 전송은 없다.
8. 기존 작품 PNG, 기록 인쇄, 편집 백업 JSON과 파일 이름 및 데이터 취급을 명확히 구분한다.

## 공개 출시 전 차단 조건
- 실제 Android Chrome / iOS Safari 터치/키보드/저장/다운로드 사용자 시험.
- 모바일 320–430px, 큰 글자, 스크린리더/키보드, 느린 디바이스와 100개 이상 조각 부하 점검.

- 사용자 검토와 명시적인 운영 병합/배포 결정. **Draft PR 상태에서는 운영 코드를 바꾸지 않는다.**
