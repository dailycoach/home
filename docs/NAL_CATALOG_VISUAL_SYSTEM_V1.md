# NAL 카탈로그 비주얼 시스템 v1.0

작성일: 2026-08-01
적용 범위: `/nal/` 홈, 목록, 프로그램 8종 상세, 상품 4종 상세

## 1. 목적

NAL GATHER, CLASS, SHOP을 서로 다른 서비스처럼 분리하지 않고 하나의 큐레이션 라이프스타일 경험으로 연결한다. 실제 운영 사실이 확정되지 않은 단계에서는 날짜, 가격, 정원, 재고, 신청·구매 URL을 만들지 않으며 이미지도 실제 행사 기록이나 판매 확정 제품처럼 표현하지 않는다.

기존 `/nal/` 경로, 검색·필터·정렬, 로컬 찜·최근 본 항목, 공개 데이터 규칙, 미술심리코칭 6주 과정, SEO·sitemap, 데이터 기반 상세 생성 구조는 유지한다.

| 본문 | Deep Charcoal | `#202126` | 제목·본문·경계 |
| 공통 행동 | Electric Cobalt | `#4055D8` | CTA·포커스·단계 번호 |

| SHOP | Acid Lime | `#D7F35A` | 상품 배지·도구 표시 |

타이포그래피는 저장소와 운영체제에 이미 있는 Paperlogy, Pretendard, SUIT, Noto Sans KR, Space Grotesk, Archivo, Inter 계열을 우선한다. 한글 글리프가 없는 환경에서는 저장소의 Gowun Batang Bold를 폴백으로 사용한다. 외부 폰트 네트워크 요청은 없다.

## 3. 공통 시각 언어

- 조용한 자연광과 Warm Ivory 기반의 낮은 채도
- 종이, 노트, 필기도구, 카드처럼 실제로 만질 수 있는 재료
- 완성 결과보다 선택하고 기록하고 배열하는 과정
- 얼굴보다 손, 자리, 대화의 거리와 흐름
- 카드와 제품을 확정 패키지로 단정하지 않는 에디토리얼 모형
- 과도한 그라데이션이나 둥근 카드 대신 직선, 넓은 여백, 한 가지 강한 색
- 이미지 위 핵심 카피를 얹지 않고 이미지와 텍스트 영역을 분리

## 5. 카드 시스템

카드는 이미지 → NAL 영역·상태 → 제목 → 한 문장 설명 → 확인된 방식·시간 → 미확정 안내 → 찜 순서로 읽힌다.

- GATHER·CLASS: 데스크톱 `8:5`, 모바일 `4:3`
- SHOP: `1:1`
- 이미지에는 `width`, `height`, `aspect-ratio`를 함께 사용해 공간을 예약한다.
- 목록 하단 이미지는 lazy loading, 상세 상단 이미지는 eager loading과 preload를 사용한다.
- 이미지 실패 시 `IMAGE / READY` 폴백이 해당 미디어 영역 안에서만 표시된다.
- 공개 카탈로그 12종의 정상 환경에서는 폴백이 표시되지 않는다.
- 모바일 제목은 최대 2줄, 본문은 최소 16px, 찜 버튼은 최소 44px이다.
- 카드 전체 링크와 찜 버튼은 z-index와 별도 버튼 요소로 키보드·포인터 충돌을 피한다.

## 6. 상세 시스템

상단은 텍스트보다 이미지가 조금 더 넓은 비대칭 그리드다. 모바일에서는 전용 `3:4` 프로그램 이미지를 먼저 보여주고 텍스트를 이어 붙인다. 상품은 `1:1` 비율을 유지한다.

프로그램 상세 순서:

1. 이런 경험입니다
2. 무엇을 하게 되나요
3. 이런 분에게 잘 맞습니다
4. 함께 사용하는 도구
5. 진행자
6. 참여 전 알아둘 점
7. 일정 오픈 전 안내

상품 상세 순서:

1. 이 도구가 여는 대화
2. 카드 또는 도구의 사용 방식
3. 혼자 사용할 때
4. 함께 사용할 때
5. 모임·클래스에서 사용할 때
6. 연결 프로그램
7. 제품 준비 상태

데이터가 없는 선택 섹션은 렌더링하지 않는다. 일정·참가비 또는 가격·재고·배송이 확정되지 않은 상태는 마지막 안내 섹션과 비활성 CTA에서 명시한다.

## 7. 홈 큐레이션과 관계

홈의 `CURATED THREE`는 `featured` 항목 중 `featuredOrder`가 가장 앞선 클래스 1종, 모임 1종, 상품 1종을 고른다. 배열 순서나 무작위에 의존하지 않는다.

`USED TOGETHER`는 공개 상품의 `relatedProgramIds`와 공개 프로그램만 조합한다. 현재 노출 가능한 관계는 다음과 같다.

| 프로그램 | 상품 |
|---|---|
| 감정카드 대화모임 | 감정카드 |
| 감정카드로 만나는 나 | 감정카드 |
| 자기이해 글쓰기 모임 | 코칭 질문카드 |
| 코치들의 대화와 실습 모임 | 코칭 질문카드 |
| 관계 속 나의 대화 방식 | 관계 질문카드 |

미술심리 워크북과 원데이클래스 키트는 관계 ID를 유지하지만 비공개 상품이므로 화면에 노출하지 않는다.

## 8. 데이터 확장

프로그램에 다음 선택 필드를 추가했다.

- `coverImageMobile`
- `coverImageAlt`
- `activities`
- `recommendedFor`
- `featuredOrder`

상품에 다음 선택 필드를 추가했다.

- `coverImageAlt`
- `galleryAlts`
- `visualNote`
- `featuredOrder`

생성 스크립트는 상세 항목별 대표 이미지를 OG·Twitter·JSON-LD 이미지로 연결하고 프로그램 모바일 이미지를 preload `imagesrcset`에 포함한다. JavaScript가 꺼진 환경에서도 목록과 상세 대표 이미지·핵심 설명을 볼 수 있다.

## 9. 사실성·접근성 원칙

- 생성 이미지는 프로그램 활동을 설명하는 에디토리얼 콘셉트이며 실제 행사 기록이 아니다.
- 상품 이미지에는 제품 확정본이 아니라는 `visualNote`를 항상 표시한다.
- 의미 이미지에는 장면을 설명하는 alt를 사용하고 장식 조합은 상위 요소에서 숨긴다.
- 상태는 색뿐 아니라 텍스트 배지와 비활성 버튼 문구로 전달한다.
- `:focus-visible`, skip link, `prefers-reduced-motion`, 강제 색상 모드를 유지한다.
- 치료·진단·효과 보장 표현을 사용하지 않는다.
