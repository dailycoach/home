# WAVE 9 · 달항아리 PORCELAIN V3 — 독립 미술 시안 검토

**작성** 2026-10-19 · **상태** 디자인 시안만 제작 · **운영 사이트 미반영**

## 목적과 경계
이 단계는 바로 운영 백자를 교체하는 일이 아니다. 기존 WAVE8 한 화면 작업실의 편집 경험은 유지하면서, 완성된 작품의 미술적 품질을 높이기 위한 **빈 달항아리 자체의 시각적 연구**다. 이미 사용 중인 작품, 96개 자개, 1600×1800 좌표, 로컬 저장, PNG/카드 렌더러, 외부 자유배치 및 기존 V2/선화 도안은 전혀 수정하지 않는다.

## 최초 기하학 시안
- `design/moonjar-wave9/porcelain-day.svg` — 따뜻한 한지 배경 위의 유백색 항아리.
- `design/moonjar-wave9/porcelain-night.svg` — 청먹색 바탕에도 백자 고유의 따뜻한 흰색을 유지.
- 두 SVG 모두 **1600×1800 viewBox**, 자체 베지어 곡선으로 제작한 독립 원본, 외부 이미지 참조 없음, 오프라인 편집 가능.
- 일반적인 달항아리의 작은 구연부, 풍만한 몸통, 조용한 비대칭, 완만한 하단 곡선을 새로 그렸다.
- 툴의 기본 배경 이미지로 연결하지 않는다. 미술 검토 후 별도 명시적 `canvasVariant`로만 추가할 후보이며, 구형 배경을 덮지 않는다.

## 동시 제공한 독립 검토 패키지(대화 파일)
`moonjar_wave9_art_study_v1.zip`: 2개의 SVG 원본, 2개의 1600×1800 PNG, 400×450 WebP 2개, 아트 디렉션 비교 이미지, 오프라인 전시형 `review.html`, 재현 스크립트 `build_moonjar_v3.py`, SHA-256 검증 스크립트 및 검토 노트.

해당 PNG는 SVG 마스터 위에 파이썬으로 매우 낮은 진폭의 자체 제작 도자기 유약·확산광을 더한 **실험적 미술 검토 출력**이다. PNG 세부 픽셀은 원본 SVG만 재래스터화한 것과 같지 않다. PNG 재현·해시 검증은 제공된 `build_moonjar_v3.py`를 기준으로 한다. GitHub에 올린 SVG는 동일한 스터디 기하학의 편집 가능한 벡터 기초자료다.

## 현재 미술적 판단 (합격을 과장하지 않는다)
- **개선된 부분:** 항아리가 빈 상태에서도 일정한 조형적 무게를 지닌다. 밝은/어두운 바탕의 톤 차이가 명확하다. 기존의 과한 피부색 마블 무늬를 절제하고 3D 플라스틱처럼 번쩍이는 반사광도 억제했다.
- **여전히 남은 결함:** 구연부의 규칙성이 자연 도자기보다 강하다. 외곽 실루엣, 미세한 유약 투명도, 도공의 손맛이 사실적인 수준까지 올라오지 않았다. 따라서 **상품 디자인 최종 승인이나 8.5/10 이상의 미술 완성도를 선언하지 않는다.**
- **다음 필요한 시각 QA:** 기존 자개 A~H 96개를 실제 이미지로 중첩하여 낮/밤, 빈 상태·1·8·48·96개 배치에서 판단한다. 현재 검토 패키지에는 기존 96개의 자개 바이너리가 포함되지 않으며, 임의의 가짜 자개를 실자개처럼 제시하지 않는다.

## 출시 차단 게이트
1. 원본 자개 96개 해시 불변. 항아리 밖 자유 배치 및 전체 1600×1800 출력 불변.
2. 백자 도안 추가는 **새 경로, 새 variant ID, 새 체크섬, 기존 도안 보존** 형태로만 구현.
3. 기존 프로젝트의 optional `scene.canvasVariant` 필드가 없는 경우 무조건 기존 배경으로 해석.
4. 앱 화면 SVG / 완성 PNG / 작품 카드의 실제 출력 동일성 검사 필수.
5. 미술감독 검토, 사용자 시안 확인, 모바일 실기기 및 TalkBack/VoiceOver 확인 후에만 운영 반영.
6. 국립중앙박물관 사진 등 제3자 사진의 가져오기·변형·배포 금지. 일반적 역사·형태 연구만 진행.
