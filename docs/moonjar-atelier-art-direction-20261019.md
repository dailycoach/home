# 빛을 담는 달항아리 · ATELIER 01 — UX/UI 디자인 개편

작성: 2026-10-19 / 작업 범위: `/activities/moonjar/` / 기준: PR #193 `feat/moonjar-free-decorating-flow` 위에 적용하는 디자인 전용 브랜치

## 디자인 진단

기존은 녹색 계열 그라디언트, 반복되는 둥근 카드, 둥근 버튼/캡슐 탭, 여러 종류의 그림자, 불필요하게 떠 있는 툴바가 겹쳐서 공예 활동보다 흔한 SaaS 템플릿에 가깝다. 기존의 `refinement.css`가 원래 `styles.css`의 시각 스타일을 덧씌운 뒤 W7 및 자유꾸미기 스타일이 다시 덮어써 디자인 언어가 서로 충돌했다.

## 목표

**달항아리를 꾸미는 온라인 공방이자 한 권의 작은 전시 도록.** 기본 화면은 작품이 주인공이고, 도구는 눈에 잘 띄되 그 자체가 시각적 주인공이 되지 않는다.

| 축 | 구현 방향 | 하지 않는 것 |
| --- | --- | --- |
| 물성 | 한지 아이보리, 먹색, 미세한 백자·황동 계열 보조색 | 무지개·네온·과한 광택 |
| 타이포그래피 | 저장소에 이미 있는 Gowun Batang Bold 한국어 폰트 재사용, 본문은 고가독 시스템 산세리프 | 외부 폰트 서비스·텍스트 이미지 |
| 구성 | 비대칭 여백, 세로 구분선, 작품을 넓게 보여주는 중앙 작업 무대 | 같은 모양의 카드 반복 |
| 컴포넌트 | 2~3px 모서리, hairline 경계, 선택 상태 2px 강조, 주요 행동만 진한 배경 | pill 버튼·전체 그림자·부유 효과 |
| 편집 | 자개 96종 원본과 조각 위치를 그대로 유지, 모바일 작업 패널 높이 유지 | 원본 자개 테두리 영구 추가 |
| 기록 | 한 번의 질문·자유꾸미기 흐름, 기본 비공유, 옵션 기록 | 진단·평가·AI 심리 판독 |
| 완성 | 결과 이미지와 카드 우선, 기록은 선택 펼침 | 결과보다 설명이 앞서는 화면 |

## 이번 PR 변경

1. 기존 디자인 덧씌우기 파일 `refinement.css`를 편집 가능한 영역별 아트 디렉션 CSS로 전면 교체했다. 스타일 파일을 추가하지 않았다.
2. `index.html` 스타일시트 순서를 `styles → nacre visibility → decorating flow → refinement`로 정리하고 디자인 파일의 버전을 갱신했다. 기능 레이아웃 CSS를 마지막 테마로 임의 덮지 않도록 선택자를 특정했다.
3. 시작 페이지·머리글·작업실·자개 팔레트·편집 버튼·7단계 이야기·모바일 하단 탭·완성 페이지·카드 모달의 타이포그래피와 색/선/그림자를 맞췄다.
4. 모바일 320·360·390·430px을 우선으로 고려하여 첫 작업 CTA, 작업실 자개 가시성 및 하단 트레이, 카드 다운로드 고정 버튼을 유지했다.
5. `scripts/check-moonjar-browser.mjs`에 테마 토큰, CTA 색, 그라디언트 제거, 폰트 연결, CSS 순서 검증을 추가했다.

## 검증 기준과 잔여 리스크

- **자동**: Node 도메인·저장·저작물 무결성 테스트, Chromium 모바일·데스크톱 실제 화면 캡처, Chromium/WebKit 다중 해상도 및 저장·복원·PNG 내보내기 비교.
- **디자인 리뷰 필수**: GitHub Actions `moonjar-mobile-ux-qa` 이미지의 모바일 시작 화면/자개 팔레트/작업실/마무리/카드와 데스크톱 화면을 실제로 눈으로 검토한다. 자동 테스트 PASS는 미감·호흡·완성도 PASS가 아니다.
- **실기기 검증 미완료**: 안드로이드 크롬과 iOS 사파리, 키보드/가상키보드, TalkBack/VoiceOver, 저장 파일 다운로드 및 손가락 조작.
- **기존 데이터/이미지 불변**: 기존 사용자의 IndexedDB 저장 구조, 과거 작품 JSON, 자개 원본 96종, 백자 2종·기존 선화 및 작품 PNG 렌더링 코드 변경 없음.
- **출시**: 디자인 PR은 운영 사이트를 변경하지 않는다. UI 리뷰·회귀검증 후 기존 자유 꾸미기 PR(#193)에 통합하고 운영 반영 여부를 별도 결정한다.
