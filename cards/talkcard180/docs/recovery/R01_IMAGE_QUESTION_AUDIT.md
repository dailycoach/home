# TALK CARD 180 v2.1 — R01 IMAGE QUESTION AUDIT

- 현재 상태: **ARCHIVED — v2.1 런타임 미사용**
- 대상: IMAGE 60장 메인 질문 전수
- 보존: 카드 ID, 이미지, ALT, Follow-up 원문
- 제품 결정: IMAGE 카드에는 질문·Follow-up을 표시하지 않고 이미지 단독 자유연상으로 운영
- 평가 기준: Q1 이미지 여백 / Q2 해석 비강요 / Q3 자기분석 불필요 / Q4 답의 다양성 / Q5 이미지 중심성

> 2026-08-17 결정으로 아래 감사 결과와 대안 문구는 변경 이력용으로만 보존한다. `runtime-cards.js` 원본 데이터는 삭제하지 않지만, v2.1 View·Pick Engine·sessionStorage에는 메인 질문과 Follow-up이 들어가지 않는다. 기존 R07 질문 반영 단계는 실행하지 않는다.

## 6. 보관 규칙

1. KEEP·SOFTEN·REWRITE 분류와 대안 문구는 감사 기록으로 유지한다.
2. `runtime-cards.js`, 이미지 매니페스트, ID, 파일 경로, ALT는 변경하지 않는다.
3. v2.1 View는 IMAGE 카드에서 `prompt`와 `followup`을 가져오지 않는다.
4. Pick Engine과 sessionStorage에는 IMAGE 질문 관련 필드가 존재하지 않는다.
5. R07 질문 문구 반영은 취소한다.
