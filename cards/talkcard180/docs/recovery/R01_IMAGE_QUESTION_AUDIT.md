# R01 IMAGE QUESTION AUDIT

## RUN

R01 — IMAGE QUESTION AUDIT

## STATUS

COMPLETE

## SCOPE

- 대상: `data/image-card-manifest.json`의 IMAGE main prompt 60개
- 보존: 카드 ID, 이미지, ALT, scene/composition, follow-up 원문
- 제외: 실제 prompt 데이터 수정 — R07에서 승인된 항목만 반영
- 원칙: 이미지가 먼저 보이고, main prompt는 사용자가 `질문 열기`를 눌렀을 때만 공개

## DECISION RULE

- **KEEP** — 관찰·연상·이야기를 열어두고 이미지에 한 가지 의미를 부여하지 않는다.
- **SOFTEN** — 기본 방향은 열려 있으나 사람·시절·관계·기다림 같은 한정어가 답의 범위를 좁힌다.
- **REWRITE** — 현재의 자기 상태, 감정, 미래, 관계에 직접 투사하도록 하거나 이미지가 장식으로 밀려난다.

## QA QUESTIONS

- **Q1** 이미지 자체를 충분히 볼 여백이 있는가?
- **Q2** 질문이 하나의 해석을 강요하지 않는가?
- **Q3** 답하기 위해 심리학적 자기분석이 필요하지 않은가?
- **Q4** 두 사람 이상이 서로 다른 답을 말할 수 있는가?
- **Q5** 질문 때문에 이미지가 장식으로 전락하지 않는가?

Q1은 문장보다 노출 순서의 문제다. R03 Pilot에서 모든 IMAGE 카드에 `IMAGE ONLY → 질문 열기 → 한 걸음 더`를 적용하는 것을 전제로 60장 모두 **UX LOCK**으로 판정했다. 아래 `현재 미통과`는 현 main prompt 기준 Q2~Q5만 표시한다. 제안 문구는 표시된 미통과 항목을 해소한다.
