SIX TRUST POLICIES

서비스가 지키는 여섯 가지 경계

01

Achievement, not type

배지는 심리유형·원점수·진단이 아니라 지정된 참여·활동·성취조건을 설명합니다.

02

Private by default

원점수, 세부 심리프로파일, 상담·코칭 대화와 자유서술은 공개 Credential 기본필드에 포함하지 않습니다.

03

Official information and operation are separate

공식 제품 안내페이지와 기관별 실제 이용경로를 분리해 표시합니다.

04

Demo and live are separate

실제 발급·검증·기관별 플랫폼 연결이 확정되지 않은 기능은 Demo 또는 Pending으로 표시합니다.

05

Minor / guardian policy pending

미성년자 실사업은 기관별 참여·보호자·개인정보 정책 검토 후 운영합니다.

06

Non-medical boundary

허브와 배지는 의료·진단·응급서비스를 대체하지 않습니다.

PUBLIC / PRIVATE

Credential에 공개할 정보와
포함하지 않을 정보를 나눕니다.

PUBLIC CREDENTIAL FIELDS

  • 배지명과 프로그램명
  • 취득조건과 확인 가능한 성취기준
  • 발급주체·발급일·유효상태
  • 공유·검증에 필요한 공개정보

PRIVATE BY DEFAULT

  • 원점수와 세부 심리프로파일
  • 상담·코칭 대화
  • 자유서술과 개인 민감정보
  • 동의 없는 기관 간 데이터 이전

PARTICIPANT CONSENT 참여 전 기관 안내문에서 수집정보·이용목적·공개범위·철회방법·문의주체에 대한 동의 범위를 확인합니다.
