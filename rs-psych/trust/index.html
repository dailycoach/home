01 · SERVICE BOUNDARY

검사결과를 성장행동으로 연결하는 교육·코칭 경험입니다.

RS PSYCH는 공개 확인된 심리·진로검사 자산과 DAILYCOACHING의 해석·성찰·실천 경험을 연결합니다. 검사 결과를 사람에 대한 확정판정으로 사용하지 않습니다.

의료·위기 서비스가 아닙니다.

의료진단, 정신질환 치료, 응급지원, 위기상담을 제공하지 않습니다. 긴급한 위험이나 안전 문제가 있는 경우 이 웹페이지가 아니라 지역의 응급·보건·전문기관을 이용해야 합니다.

02 · PRIVATE BY DEFAULT

개인내용을 입력받지 않는 데모부터 시작합니다.

현재 공개 버전의 장면 선택과 Practice 7은 고정 Enum과 데모 콘텐츠로만 작동합니다. 자유서술, 이름, 연락처, 검사점수, 상담내용을 입력받거나 저장하지 않습니다.

공개 화면에 표시 가능한 정보

  • 고정된 문제장면 ID
  • 검사·성장경로의 일반 설명
  • Credential 성취기준
  • 운영·근거 상태

공개 Credential에서 제외할 정보

  • 세부 심리점수와 원응답
  • 성격·심리유형의 낙인식 표기
  • 상담내용과 자유서술
  • 민감한 마음상태와 보호자 메모

03 · ACHIEVEMENT, NOT TYPE

심리특성이 아니라 확인 가능한 경험을 설명합니다.

Credential Preview는 검사 참여, 결과리뷰, 성찰질문 선택, 작은 실천과 회고처럼 관찰 가능한 성장경험의 기준을 설명합니다.

현재는 Preview입니다.

발급주체, 검증 제공자, 취소·만료·갱신 정책이 확정되기 전에는 실제 발급·검증·파트너십을 주장하지 않습니다.

04 · PROVIDER STANDARD

전문가 프로필은 검증과 공개동의 이후에만 노출합니다.

현재 버전은 실존 코치나 상담사를 흉내 내는 가짜 프로필, 배정화면, 관리자 대시보드를 만들지 않습니다.

미래 운영 게이트

  • 신원 및 자격 확인
  • 공개 가능한 전문영역 합의
  • 역할과 서비스 경계 표시
  • 프로필 공개동의
  • 배정·기록·품질·분쟁 기준

현재 공개상태

  • Provider OS는 Blueprint 수준
  • 실제 전문가 목록 없음
  • 실제 예약·결제·정산 없음
  • 가짜 후기·성과 주장 없음

05 · EVIDENCE STATUS

‘존재 확인’과 ‘현재 운영 확인’을 분리합니다.

웹페이지 전체에서 아래 상태를 사용합니다.

상태의미

VALIDATION NOT PUBLICLY CONFIRMED자체 도구의 신뢰도·타당도·규준 등 공개 검증자료를 확인하지 못했습니다.

06 · SAFETY ROUTING

코칭으로 다룰 수 없는 상황을 모호하게 만들지 않습니다.

가정폭력, 학대, 성폭력, 자해·자살 위험, 아동 안전, 응급상황처럼 즉각적인 안전 판단과 전문개입이 필요한 상황은 일반 심리코칭·진로코칭 경로와 분리되어야 합니다.

긴급 상황

즉각적인 위험이 있다면 이 서비스의 검사·Practice 7을 진행하지 말고, 사용자가 있는 지역의 응급서비스·보건기관·경찰·전문 위기지원기관에 직접 연락해야 합니다. 지역과 상황을 확인하지 않은 전화번호를 임의로 제시하지 않습니다.
